# S4 表演外化

输入：`03_script/scene-XX.md` 剧本页。产出：每个节拍的 C 层可观察量（动作 / 部位表情 / 视线 / 空间 / 节奏 / 声音），写回剧本页的"外化"列，供 S5 分镜卡直接取用。本阶段不停靠。

## 4.0 角色声音表（先于任何台词）

每个说话的角色一张，写在 `ip.md 与 assets/characters.md`。没有它，所有角色都会说同一种"克制的人话"。

```
词汇：常用的 5 个词 / 绝不用的 5 个词（例：母亲绝不说"搬走"、"走"，只说"面"、"钥匙"、"冷"）
句长：短（≤ 6 字）/ 中 / 长；打断别人还是被打断
口头禅或习惯句式：
回避方式：被问到痛处时做什么（转移到食物 / 反问 / 沉默 / 开玩笑）
绝不会做的可观察行为：
语音：语速 / 音量 / 方言 / 音色描述（可观察）
```

写完台词后逐句核对：这句是不是只有 TA 会这么说？换成另一个角色说也成立 → 重写。

## 4.0b 语域选择

§4.1 的"人话五关"默认是正剧语域。先按概念卡的基调选语域，再套对应规则：

| 语域 | 规则差异 | 透镜 |
|---|---|---|
| 正剧（默认） | §4.1 全部；潜台词优先 | — |
| 冷面 | 台词内容异常、语气正常；无停顿、匀速、不看对方也不回避 | L7 |
| 反讽 | 台词与动作相反（说"我不急"同时看表）；灾难用最短的句子 | L8 |
| 喜剧 | 三拍：铺垫（正常）→ 落空（意外）→ 加码（更糟）；笑点落在动作或音效上，不落在台词上；台词可以更长但必须被打断 | L9 |
| 高语域 | 允许修辞、排比、长句，但每段高语域后必须跟一个日常动作把它拉回地面（喝水、系鞋带） | — |

## 4.0c 策略列必须是可演的动词（L12）

节拍表"策略"列只接受 **及物动词 + 对象**：恳求她、审问他、哄她、羞辱他、收买她、无视他、逗她。形容词和心理状态（"表现出不舍"）不接受。每个动词配一个身体证据（恳求 = 前倾 + 手伸出；无视 = 继续原动作 + 不抬眼）。同一场戏同一角色至少换 2 次动词，换动词时身体证据必须跟着换。

台词的写作规则（五关、副词规则、张力六源、语域、声音表）在 `stage-3c-script.md` §3c.5，本阶段不重写台词，只把剧本页的动作行与台词四件套转成模型可观察量。

## 4.4 表演外化

通道与幅度由参数卡决定（`scene-parameters.md` §二 表演外化）：内收用部位级，外放用身体级，强度高的峰值动作是停住。

抽象情绪 → 可观察量，六个通道任选 ≥ 2 个（查 `externalization-lexicon.md`）：

| 通道 | 写什么 |
|---|---|
| 动作 | 手在干什么、脚步、身体重心、与物件的接触 |
| 表情 | 具体部位：眉、眼睑、嘴角、下颌、吞咽；不用成语 `[官方]` |
| 视线 | 看对方 / 看物件 / 看地 / 看窗外 / 避开后又看回 |
| 空间 | 靠近 / 后退 / 侧身 / 背对 / 坐下站起；距离数字化（一步、一臂、半米） |
| 节奏 | 停顿秒数、动作快慢、说话前的延迟 |
| 摄影 | 推近 / 停住 / 焦点转移 / 景别变化 |
| 声音 | 呼吸、吞咽、物件碰撞、环境音突然安静 |

**表演弧**：一个 clip 内的角色状态用"起点 → 触发 → 峰值 → 收束"四点写，每点绑一个时间戳。峰值不一定是最大动作，可以是最长的静止。

**听戏比说戏重要**：对白镜头里，被拍到的听者必须有一个可观察的变化（眨眼频率、手指停住、呼吸、转头）。

## 4.5 Seedance 2.5 对台词的执行约束

以下为通用约束；密度、方向、强度带来的附加约束（打断的相邻窗写法、高音量写法、快动作三句法）见 `scene-parameters.md` §二 模型执行。

| 约束 | 规则 | 标签 |
|---|---|---|
| 逐字 | 引号内文字模型照念；不在引号外写"说了一句安慰的话" | `[官方示例]` |
| 说话人 | `台词 (角色名): "…"` 或 "A 说："…"" | `[官方示例]` |
| 语言 | Prompt 里点明语言 / 口音（"中文普通话"、"东北口音"、"英语"） | `[官方]` 编辑示例 + `[第三方]` |
| 时间窗 | 每句给起止秒；总台词时长上限与语速估算由参数卡决定：内收 4 字/s、≤ 2/3；密 / 外放 6 字/s、≤ 3/4（校验脚本读 E 层「参数」行） | `[第三方]` + `[推论]` |
| 嘴部状态 | 非说话时段写"闭着嘴 / 抿嘴 / 嘴微张但不出声" | `[第三方]` |
| 密度 | 10 秒内 ≤ 3 句；两句之间至少 1 秒动作或反应 | `[推论]` |
| 多人 | 同框同时说话高风险；默认：说话者单人近景或越肩，听者反应镜头分开；两人轮流说时每人一段时间窗不重叠 | `[第三方]` 2.0 报告 + `[推论]` |
| 口型语言 | 中文最稳，英文其次，日/韩长句易漂 | `[第三方]` |
| 画外音 | 允许，写"画外传来 A 的声音："…""；画面里的人不动嘴 | `[推论]` |
| 音色 | 有音频参考时"图 1 使用音频 1 音色"；无参考时用可观察描述（年龄段、沙哑/清亮、音高） | `[官方]` |
