# S4 表演外化

输入可以是剧本页，也可以是直接表演需求。先读 `emotion-performance.md` 并按需检索完整条目，产出有序表演块（C 层）及内部核对信息。写回剧本页对应字段，或直接交付测试片段；本阶段不停靠。无台词测试跳过声音表和语域选择。

## 4.0 承接人物声音，不重新规定句法

人物语言开发统一读 `character-scene-development.md` §四，按需写入现有 `ip.md`。本阶段只补实际执行需要的声音信息，不要求先填声音表才能试写。

```
语音：语速 / 音量 / 方言 / 音色描述（可观察）
当前说法：哪些已选定的音高、呼吸、停顿或重音确需呈现
用户锁定：逐字台词 / 口音 / 既定表演，不自动修改
```

倾听可以保持不动，也可以发生变化；不为表现“听见了”让每句都触发新动作。表演发现可按 `creative-loop.md` 回流，但不擅改已确认台词或把本次回避写成人物永久习惯。

## 4.0b 语域选择

S3c §3c.5 的台词检查默认是正剧语域。先按概念卡的基调选语域，再套对应规则：

| 语域 | 规则差异 | 透镜 |
|---|---|---|
| 正剧（默认） | S3c 台词检查；潜台词可选 | — |
| 冷面 | 可让内容与平常语气产生反差；停顿和视线按人物决定 | L7 |
| 反讽 | 可来自语境、信息差或言行反差；不要求动作反说，也不规定灾难必须短句 | L8 |
| 喜剧 | 可用铺垫/落差/加码，也可让语言或表演本身成立；打断不是必需 | L9 |
| 高语域 | 修辞、排比、长句须符合人物；可以连续表达，不强加日常动作 | — |

## 4.0c 策略与可观察表演不一一对应（L12）

需要给演员沟通意图时，可用“恳求她、审问他”等动词留在 A 层。不要建立“恳求=前倾伸手”之类映射；同一意图能有不同表演，同一动作也可有不同意图。C 层承接本场已经选择的可见可听表现，允许持续状态和无新增肢体动作。

对白诊断与人物声音在 `character-scene-development.md`，剧本交付与估时在 `stage-3c-script.md` §3c.5。本阶段不重写台词，只把已选动作与说法转成模型可观察量。

## 4.4 表演外化

强度、克制与动作幅度分别判断；峰值由用户目标与选定条目决定，可持续爆发或受控。完整规则统一在 `emotion-performance.md`，不以场景参数覆盖原文。

抽象情绪由可观察证据支持，按需选择以下通道；不设最少通道数。库外写法可查 `externalization-lexicon.md`：

| 通道 | 写什么 |
|---|---|
| 动作 | 手在干什么、脚步、身体重心、与物件的接触 |
| 表情 | 具体部位：眉、眼睑、嘴角、下颌、吞咽；描述性语句优先、少用成语 `[官方建议]` |
| 视线 | 看对方 / 看物件 / 看地 / 看窗外 / 避开后又看回 |
| 空间 | 靠近 / 后退 / 侧身 / 背对 / 坐下站起；距离数字化（一步、一臂、半米） |
| 节奏 | 停顿秒数、动作快慢、说话前的延迟 |
| 摄影（S5 可见性条件，不计表演通道） | 景别、遮挡、焦点是否能呈现关键细节 |
| 声音 | 呼吸、吞咽、物件碰撞、环境音突然安静 |

**表演编排**：按内容划分持续或变化的节拍；需要弧线时从起态通向目标高光与末态，不固定四拍。同步与先后关系保留在完整正文，末态不强制静止或平静。

**听与回应**：听者可以变化，也可以持续控制住反应；不强迫每句配新动作。

## 4.5 Seedance 2.5 对台词的执行约束

技术执行与创作语感分开：估时取显式语速，不由情绪推算。台词给独立时间窗，和表演可以同步，见 `production-workflow.md`。

| 约束 | 规则 | 标签 |
|---|---|---|
| 逐字 | 引号内写期望逐字输出的文字（实际执行待验证）；不在引号外写"说了一句安慰的话" | `[官方示例]` |
| 说话人 | `台词 (角色名): "…"` 或 "A 说："…"" | `[官方示例]` |
| 语言 | Prompt 里点明语言 / 口音（"中文普通话"、"东北口音"、"英语"） | `[官方]` 编辑示例 + `[第三方]` |
| 时间窗 | 每句给起止秒；总台词时长上限与语速估算由参数卡决定：默认 4 字/s、≤ 2/3；明确密集对白只改变占比至≤3/4，不自动提高语速，可用 E 层显式估时参数覆盖（见场景参数卡）；强度与外放不自动提速 | `[第三方]` + `[推论]` |
| 嘴部状态 | 非说话时段写"闭着嘴 / 抿嘴 / 嘴微张但不出声" | `[第三方]` |
| 密度 | 按语速与时间窗估算，为必要反应留时，不设通用句数或固定间隔 | `[推论]` |
| 多人 | 同框同时说话是需验证的风险，给各说话人实际时间窗，标出重叠；单人近景、越肩、分轨或改成轮流是可协商方案，不因执行方便擅改锁定对白、重叠或镜头 | `[第三方]` 2.0 报告 + `[推论]`，非 2.5 能力禁令 |
| 口型语言 | 中文最稳，英文其次，日/韩长句易漂 | `[第三方]` |
| 画外音 | 允许，写"画外传来 A 的声音："…""；画面里的人不动嘴 | `[推论]` |
| 音色 | 有音频参考时"图 1 使用音频 1 音色"；无参考时用可观察描述（年龄段、沙哑/清亮、音高） | `[官方]` |
