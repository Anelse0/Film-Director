# S1 资源读取 · S2 任务识别

## S1 资源读取

目标：把用户手里的一切变成一张**资产登记表**，并列出缺口。模板：`templates/asset-registry.md`。

### 1.1 读什么

| 资源类型 | 读取要点 | 登记为 |
|---|---|---|
| 世界观 / 设定文档 | 时代、地点规则、技术/魔法约束、社会关系、禁忌 | `01_bible/world.md` |
| 角色小传 | 外观（可观察：年龄段、体型、发型发色、肤色、标志性服饰/配饰/疤痕）、说话方式（语速、口头禅、方言、音色）、欲望与恐惧、与他人的关系 | `01_bible/characters.md` |
| 场景 / 地点 | 空间布局（入口、窗、光源方向、主要陈设）、时刻与天气、声音环境 | `01_bible/locations.md` |
| 剧本 / 大纲 / 一句话想法 | 场景目标、冲突、已有台词 | `02_script/` 输入 |
| 参考图（角色 / 场景 / 道具 / 风格） | 每张图的"可提供什么"：外观 ID / 服装 / 场景构图 / 光影滤镜 / 风格；**同时记录"不该被参考的部分"**（背景、姿势、文字） | `01_bible/assets.md` |
| 参考视频 | 提供什么：动作 / 表情 / 运镜 / 白模动线 / 风格；时长；是否含四肢精细动作 | `01_bible/assets.md` |
| 音频 | 音色 / 台词 / 音乐；时长；语言 | `01_bible/assets.md` |
| 已有成片（要编辑或延长） | 时长、宽高比、格式、哪些秒段要动、哪些必须不变 | `01_bible/assets.md` + S2 编辑分支 |
| 分镜图 / 宫格 | 格数、是线稿还是精修、图上有无文字 | `01_bible/assets.md` |

### 1.2 登记规则

- **编号即上传顺序**。登记表里给每个素材一个稳定 ID（`img1`、`vid1`、`aud1`），并注明**最终上传顺序必须与编号一致**；如果用户之后调整顺序，登记表与所有 Prompt 同步改。
- **一素材一职责**：登记时就写"参考什么 / 不参考什么"。一张角色图同时想当外观参考和场景参考 → 拆成两个用途，或让用户提供裁切。
- **可观察外观锁**：每个角色从图或小传中提炼一行"外观锁"（≤ 40 字，全是可观察量），之后每个 clip Prompt 都重写这一行。
- **文字不是绑定**：图片上写的人名不作指代依据。`[官方]`

### 1.3 缺口清单

读完后列出：
- 缺失且不可替代的：角色外观（无图无描述）、场景空间关系、台词语言。→ 问用户，一次问全。
- 缺失但可推断的：时刻、天气、光源、声音环境。→ 自行推断并在 `00_brief.md` 写"假设"。
- 素材超限（图 > 30、视频总时长 > 30s、主体 > 8）：→ 提出裁减方案。

## S2 任务识别

一句话产出：**任务类型 / 入口阶段 / 生产单元（clip）数 / 锁定判定 / 输出画幅时长**。写入 `00_brief.md`。

### 2.1 任务类型判定树

```
用户有已生成的视频，要改它？
  ├─ 改画面/声音/台词/局部 → 【编辑】有锁定：ratio=adaptive, duration=-1, MOV；入口 S6 编辑模板
  ├─ 前/后接着拍        → 【延长】有锁定：ratio=adaptive, duration 自定；入口 S5（规划续写内容）→ S6 延长模板
  └─ 两段之间补过渡      → 【无缝转场】入口 S6 转场模板
否则，用户有首帧图（或首尾帧图）且要求严格从它开始？
  └─ 是 → 【首尾帧】有锁定：role=first_frame/last_frame, ratio=adaptive；入口视是否已有分镜
否则，用户有多张按顺序的分镜/关键帧图，要求严格对齐？
  └─ 是 → 【关键帧参考】无锁定；Prompt 首句"以图片 1 至图片 N 的顺序作为关键帧"
否则，用户有一张宫格分镜？
  └─ 是 → 【宫格分镜参考】无锁定；不严格对齐；≤15 格；线稿优先
否则，用户有角色/场景/风格/动作/音频参考？
  └─ 是 → 【参考生视频 R2V】无锁定
否则 → 【文生视频 T2V】无锁定
```

多个条件同时成立 → 组合任务，按"有锁定优先"决定参数，其余作参考素材。

### 2.2 入口阶段判定

| 用户已有 | 入口 |
|---|---|
| 只有想法 / 一句话 | S3 |
| 大纲或剧本（有场景、有台词） | S5（S4 仅做台词体检，不重写） |
| 剧本无台词或台词被用户判定为"假" | S4 |
| 镜头表 / 分镜（有景别与动作） | S6（S5 只补缺项：起止状态、视线、光源、声音） |
| 成片 + 问题描述 | S7 → 定位到镜头 → S5/S6 |
| 单镜快出 | S5 单卡 → S6 |

### 2.3 生产单元（clip）估算

- 1 clip ≤ 30s。剧情场景通常 15–30s/clip；单镜任务 4–10s。
- 估算方法：场景节拍数 × 平均节拍时长（对白节拍 3–5s，动作节拍 2–4s，反应/静默节拍 2–3s）→ 总秒数 → 除以 30 向上取整。
- 超过 1 个 clip 时，在 S5 决定衔接策略。

### 2.4 画幅与时长

- 无锁定任务：由用户交付平台决定（竖版 9:16 / 横版 16:9 / 21:9 …），2.5 支持 [0.4, 2.5] 任意比。`[官方]`
- 有锁定任务：跟随素材，`ratio=adaptive`。`[官方]`
- 首尾帧：两张图画幅必须一致。`[官方]`
- duration：整数秒；编辑任务 `-1`。
