# 验证账本

本 Skill 里所有 `[推论]` 和 `[未验证]` 都应该在这里被证实或推翻。这是把"纸上导演"变成"有成片证据的导演"的唯一路径。

## 记录规则

- 一次生成一行。只记录**改了一个变量**的对照，否则无法归因。
- "被执行"的判定标准：成片里能看到 Prompt 写的那个可观察量（部位、秒数、方向）。看不到就是"未执行"，不写"部分执行"。
- 三次同结果 → 可以改标签：`[推论]` → `[已验证]` 或 `[已推翻]`，改在 `seedance-2.5-capabilities.md` 或对应 reference 里，并在本文件末尾登记。

## 待验证队列（按影响排序）

1. 画外音 + 画内单人：`台词 (女儿，画外)` 写法是否稳定产生画外声音且画内人不动嘴（`stage-3` §4.5，example-02 B）。
2. 移焦"术语 + 描述"写法是否被执行（`camera-vocabulary.md`）。
3. 出画停留 ≥ 3 秒是否被执行，还是模型会补人进来（`stage-4` §5.1d）。
4. 20 秒一镜到底两人走位三次构图变化的稳定性（example-02 C）。
5. 外化词典中"部位级"表情（下唇内收、吞咽）是否可见，还是被放大成夸张表情。
6. 中文 vs 英文 Prompt 同一场景差异（`stage-5` §6.4）。
7. 画面级负向词（英文 no logo）是否有效（`capabilities` §4.4）。
8. 切镜密度：6 镜 / 30s 与 10 镜 / 30s 的稳定性差异（`capabilities` §5 冲突记录）。
