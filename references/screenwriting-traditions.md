# 剧本传统：好莱坞 · 欧洲 · 韩国

三种传统不是风格标签，是三套回答"故事怎么成立"的方法。S3b 选一种作**主传统**，最多再借另一种的一个元素，写一句为什么。三种都用等于没用。调研来源见文末，方法层引用标 `[第三方]`，转成本 Skill 写法的部分是 `[推论]`。

## 一、三种传统 × 六个维度

| 维度 | 好莱坞 | 欧洲作者电影 | 韩国（剧集与类型片） |
|---|---|---|---|
| **结构** | 三幕 / 节拍表：开场画面 → 催化 → 中点反转 → 全失 → 终局。因果链驱动，主角有目标，问题在高潮回答 | 情境重于情节：一个具体的实际问题（Dardenne《两天一夜》= 一个周末说服 16 个同事），人物在其中反复尝试；结局可开放 | 起承转结（기승전결）：起 = 建立关系不急着冲突；承 = 铺；转 = 重新定义前面一切的转折；结 = 情绪清算。集与集之间靠钩子 |
| **情绪刻画** | 情绪来自期待与结果的落差（McKee 的 gap）：人物采取最保守的行动，世界给出意外反应 | 情绪不解释、不放大；来自身体、劳动、重复与时长；道德不评判（Haneke 不解释暴力） | 情绪真诚且外露，但**延迟**：告白、秘密、危险在临界点被切断；한（怨中之悲）与 정（黏着的情）；家庭是情绪单位 |
| **人物** | 想要（want）与需要（need）分离；缺陷（flaw）与旧伤（ghost）；主角与对手是两种活法的道德论证（Truby） | 人物由处境定义（阶级、工作、钱），不由性格定义；没有"弧"也成立，有"决定"就成立 | 人物由关系网定义（家人、前任、上司）；一个不可说的秘密；对立角色往往有同一个伤口 |
| **台词** | 意图与阻碍（Sorkin）：每句台词是一次尝试；潜台词；禁止说出主题；节奏是音乐（韵律 / 音调 / 音量） | 稀少、功能性、日常；沉默是台词；不说的比说的多 | 峰值时可以直接（"我喜欢你"可以说出口），但要延迟到最后一秒；日常台词围绕吃饭、钱、家人 |
| **节奏** | 晚进早出；设置与回收；每场改变价值正负；动作与对白交替 | 时长本身是手段：真实时间、重复、等待；一场戏可以只做一件事 | 慢铺快收：前 70% 慢，最后 30% 急；情绪高点后立刻切断（"切断情绪"的剪法）；短剧变体：3 秒钩 · 15 秒一节拍 · 升-爆-勾 |
| **世界观** | 一个大谎（One Big Lie）+ 其余全真；规则有代价；世界观必须改变人物的选择 | 世界 = 社会阶层的物质化：房租、工资单、公交卡；没有"设定"，只有"条件" | 世界 = 制度与身份：财阀、兵役、高考、户籍；类型可混（Bong：喜剧滑入恐怖，在同一场戏里换类型） |

## 二、按格式选主传统 `[推论]`

| 格式 | 建议主传统 | 借什么 | 为什么 |
|---|---|---|---|
| 30 秒先导 / 单场 | 韩国（延迟 + 切断） | 好莱坞的"一个清晰想要" | 30 秒没有空间讲弧，只够一个临界点；韩式切断天然是先导片的结尾 |
| 60–120 秒短剧单集 | 韩国短剧变体（钩 · 节拍 · 勾） | 好莱坞的设置回收 | 格式本身要求密度 |
| 3–8 分钟短片 | 好莱坞（起承转合完整）或欧洲（一个实际问题） | 韩国的"转" | 有空间放一个真正的中点 |
| 多集 | 韩国（每集钩子 + 关系网） | 好莱坞的季弧 | 集与集靠关系推进，不靠事件 |
| 情绪核心 = 悲 | 欧洲（不解释）或韩国（延迟） | — | 好莱坞式解释会把悲说破 |
| 情绪核心 = 荒诞 / 制度 | 欧洲（Lanthimos 系）+ 韩国类型混合 | — | 制度感需要冷处理 |
| 商业 / 广告 | 好莱坞（清晰目标 + 回收） | 韩国钩子 | 观众要在 5 秒内知道要什么 |

## 三、可迁移规则（进 S3b / S3c 的具体写法）

### 结构
1. **一句话故事必须含"但是"**（好莱坞）。没有"但是"就没有阻碍。
2. **每场戏改变一个价值的正负**（McKee）：进场时希望 / 出场时绝望，或反之。场景清单每行写"+ → −"或"− → +"。
3. **转 = 重新定义**（韩国）：转折不是"发生了更大的事"，是"前面的事原来是另一回事"。30 秒先导的转必须在最后 5 秒。
4. **一个实际问题**（欧洲）：主角要解决的是能用手做的事（凑钱、找钥匙、签字），不是"和解"。
5. **晚进早出**：场景从冲突已经开始的地方进，在决定做出、后果未到时出。

### 情绪
6. **落差写法**：先写人物期待什么（一句），再写结果（一句），落差就是情绪。不写情绪词。
7. **延迟写法**（韩国）：最重要的一句话或一个动作，放到 clip 最后 3 秒；前面全是它的"差一点"。
8. **不解释写法**（欧洲）：人物不说自己为什么这样做；观众从工作、钱、身体看出来。
9. **情绪温度表**：每场一格，进场温度 → 出场温度（冷 / 温 / 灼三档或 0–10）。相邻两场方向相反，否则观众麻木。

### 人物
10. **想要 / 需要 / 缺陷 / 旧伤 / 秘密 / 绝不会做**，六格填满才算一个人物。30 秒先导只用"想要 + 秘密 + 绝不会做"。
11. **两种活法**（Truby）：双人戏里两个人代表两种"怎么活是对的"，剧本是这场争论；谁赢不重要，代价要可见。
12. **处境定义人物**（欧洲）：先写他每月挣多少、住哪、几点起床，再写他怕什么。
13. **关系网定义人物**（韩国）：先写他对三个人分别撒的三个谎。

### 台词
14. **意图与阻碍**：每句台词标注"想让对方做什么"；标注不出来的删。
15. **禁止说主题**：任何解释故事意义的句子删。
16. **副词规则**（三种传统都遵守，好莱坞最严）：
    - 动作行禁止副词与情绪形容词。"他愤怒地摔门" → "他把门摔上，门框上的灰落下来。"
    - 括号提示（wrylies）禁止：不写"（冷冷地）"、"（深情地）"。允许的括号只有：（画外）、（对 B）、（停顿 N 秒）、（语言）。
    - 台词内副词每句 ≤ 1，且不得是情绪副词。"我真的真的很想你" → "我想你。"
    - 替换表：副词 → 动作 / 停顿 / 重复 / 视线。见 `stage-3c-script.md` §台词。
17. **韩式直白只在峰值**：整个 clip 只允许一句直白台词，放在延迟点。

### 节奏
18. **慢铺快收**：30 秒先导 0–20 秒只做铺垫，20–27 秒爆，27–30 秒切断。
19. **切断情绪**：情绪最高点不停留，直接切黑或切走。不给观众"消化"的镜头。
20. **短剧密度**：60–120 秒每 15 秒一个道具 / 反转 / 台词高点；3 秒内一个认知冲突。

### 世界观
21. **一个大谎**：科幻 / 奇幻只允许一条反事实规则，其余全按现实；这条规则必须有代价，代价必须在故事里被支付。
22. **世界观三条硬规则**写在 ip.md 顶部，每场戏检查不违反。写法是可拍的："没有电"、"不能直视贵族"、"每天 18 点宵禁"。
23. **世界改变选择**：世界观元素如果不改变某个人物的某个决定，删掉。
24. **类型可混但只在一个方向**（Bong）：喜剧滑向恐怖可以，恐怖滑向喜剧再滑回来不行；一场戏只换一次类型。

## 四、误用信号

| 信号 | 说明 |
|---|---|
| 三种传统都用了 | 没有主传统，故事没有性格 |
| 30 秒先导用了三幕 | 塞不下，结果是三个都浅 |
| 欧洲传统 + 大量台词 | 欧洲的少台词不是风格是方法 |
| 韩式切断用在每场 | 切断只在峰值；每场都切等于没切 |
| 世界观设定了没人违反 | 规则没有代价，删 |
| 人物六格填满但没有"绝不会做" | 这格决定高潮：高潮就是他做了绝不会做的事，或者最终没做 |
| 动作行出现"地" | 副词进来了 |

## 五、来源

好莱坞：Snyder《Save the Cat》节拍表；McKee《Story》的 gap；Truby《The Anatomy of Story》道德论证；Sorkin MasterClass 意图与阻碍、台词即音乐；Script Magazine / Final Draft 关于 wrylies 与副词的行业共识。欧洲：Dardenne《两天一夜》结构分析；Haneke《巴黎评论》访谈；European art cinema 对经典叙事的拒绝（因果链与目标导向主角非必需）。韩国：起承转结 / 기승전결 结构；16 集 4 段（4 铺 / 4 复杂化 / 4 发展 / 4 收）；Korean melodrama 的家庭中心与 한 / 정；Bong Joon-ho 访谈（类型混合、同场换调）；短剧方法论（3 秒钩、15 秒节拍、升-爆-勾、卡点反转）。均为 `[第三方]`。
