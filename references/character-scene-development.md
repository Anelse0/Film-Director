# 人物可信度、场景吸引力与人物声音

S3b / S3c / S4 的共用判断方法，不是逐项生成清单。目标是让场景值得看、人物依据可信、语言可说，而不是去掉一切设计感。可从人物、事件、场景或对白草稿进入，正式交付仍核对故事与用户锁定内容。

## 一、每场戏的两侧问题

按本场缺口区分两种责任；需要解释创作判断时简短记录，不要求每场填满问答：

**人物这边**
- 他认为发生了什么？（不是实际发生了什么）
- 为什么选择这种回应，而不是别的？
- 他的选择改变了什么？（关系 / 信息 / 物件归属 / 位置 / 决定）

**观众这边**
- 此刻知道什么？（比人物多还是少）
- 期待什么？
- 看见哪个证据后，会改变对人物的判断？

作者负责组织吸引力，人物只依据自己此刻所知与误判行动。人物不能为方便作者揭示主题而忽然坦白，也不能为拖延情节而无依据地误会。观众的关注还可来自观察、韵律、陪伴与持续压力，不必每段都有悬念或判断翻转；真实生活式闲聊本身也不是吸引力保证。

### 交流处境：只补会影响这一段的缺口

双方已经知道什么，各自以为什么？为什么现在谈？说者希望得到什么回应，听者能否或愿否回应？现场谁能听见，称呼与表达会否因此改变？有些答案应在已有材料中找，有些可以暂不确定；不要为了填表编造秘密、旧伤、职业规则或反常习惯。

共享信息可以省略，也可以因确认、质问、安慰或强调而重说。避免向熟人解释双方都懂的背景只为告知观众；但对确有信息需求的听者，解释本身完全可成立。

## 二、叙事方式不止一种

一场戏可以靠下面任一种成立。不要求所有场景都有敌人、秘密或正负翻转；也不把"无冲突"变成新的必须。

| 方式 | 解决的问题 | 作用机制 | 适用边界 | 原始依据 |
|---|---|---|---|---|
| 冲突升级 | 利害清楚、要看人物在压力下怎么选 | 目标 → 阻力 → 尝试 → 代价，每次尝试改变局面 | 每场都升级会让观众疲劳；升级需要新信息，不是提高音量 | 通用编剧法；`causal-chain.md` |
| 欲望靠近 | 关系本身是事件；要看两人怎样一步步允许对方靠近 | 张力来自距离与允许，而非对抗；每一步靠近都有代价或风险 | 需要观众看见"允许"的证据（视线、位置、说法的改变），否则只是慢 | Sciamma 论《燃烧女子的肖像》：写作课教"好场景是冲突"，她以欲望驱动，"没有冲突不等于没有张力" `[第三方转述：Sight & Sound、RogerEbert.com 访谈]` |
| 悬念揭示 | 观众与人物信息不对等 | 揭示时机影响观众判断 | 新信息可以首次出现，但不能与既定事实冲突或只为解围临时改规则 | L1 信息差、L8 反讽落差（`director-lenses.md`） |
| 关系积累 | 相处本身值得看 | 重复、细微变化或持续陪伴承载关系 | 说明观众可感知的关系依据，不强制每段偏差或转折 | 母题与重复变义（`stage-3c` 张力六源） |
| 观察与余韵 | 看事件留下什么或处境本身 | 空间、声音、人物持续状态承载注意力 | 可占整段，也可只在结尾；按材料判断承载，不固定秒数比例 | L4 画外、出画停留（`stage-5` §5.1d） |

需要说明时写本场采用方式的理由；可以混用，不要求每场从表中选一个标签。

## 三、人物可信：不止身份标签

人物可信不来自小传字数。生活条件确实影响本场时，可查：

- 他每天必须做的一件事是什么？做的时候手在干什么？
- 他的钱、住处、作息、交通怎样影响选择？不能凭职业标签推定所有人的行为。
- 这一行 / 这种处境里有哪条外人不知道的规矩？
- 他在这个空间里有权碰什么、不能碰什么？

只有影响当前选择的未知项才是研究缺口，按 `research-to-craft.md` 补；用户已提供的角色与世界观优先，不能用研究重编。

## 四、人物声音：基础、对象与当下

声音可以有稳定性，但不是永久句式。按需要从三个层次找依据，写进 `ip.md` 或人物段；短测试只保留本场有用信息。

1. **语言基础**：生活经历、惯常语域、关注点、熟悉的词及表达习惯。依据来自已有文本、用户设定或相关材料；“母亲”“工人”不对应固定词库。
2. **面对对象**：熟悉程度、共同知识、关系与现场听众怎样影响称呼、解释量、客气程度。稳定说法也可能有效，不强制不同对象一定换句式。
3. **当前状态**：疲劳、紧急程度、情绪、想说清或不想谈，怎样影响这次表达。保护自己可以反问，也可以直接拒绝或完整说明；不用固定回避方式定义人物。

把推测标为“待试倾向”，与用户硬锁分开。共用短句不必强行写出辨识度；辨识度可以在连续选择与听说关系中积累。高语域、喜剧、修辞性作品可保留有意设计，不能都改成碎句口语。

## 五、对白审阅：先定位，再决定是否改

以一段完整交流为单位，保留必要上下文；不是每句都要接紧邻前句、换策略或改变情绪。延迟回应、非语言回应、返回早先话题、互不相让与持续状态都可能有根据。审阅时区分以下层次，只记录实际问题及证据：

| 层次 | 要判断的事 | 对应修订范围 |
|---|---|---|
| 场景 | 为什么现在谈，观众关心什么，双方知道什么 | 缺口在处境就改处境，不靠添口语词救场 |
| 人物 | 这次表达能从此人的经历、关系与当下状态理解吗 | 查已有依据，必要时研究；不擅编创伤解释一句怪话 |
| 交流 | 回应、回避、误解或突然坦白有依据吗，对方怎样接收 | 可追查早先交流及非语言信息；不要为展示张力故意不回答一个能回答的问题 |
| 措辞与说法 | 在给定语域和时间里说得出吗，词序、指代、重音是否清楚 | 已确定问题才局部调整；长句、直接话、重复、工整修辞和双方激动不是错误 |

可读出声或在文本中标明呼吸、重音作试读估计；没实际录音不能称为演员朗读验证。若词句有效而效果偏弱，先查表演与可见时间，不自动重写台词。改稿按 `creative-loop.md` 保留上一版，说明得到什么、失去什么；诊断不确定就标不确定，不能“自评高分”证明能力升级。

需要交流材料输入时读 `dialogue-observations.md`：中文语境、材料类型与迁移边界；遇到具体诊断难题时读 `dialogue-diagnostics.md`：局部修改的得失与反例。不要每次加载全部样例，也不要把样例答案搬进创作。及物动词可供演员沟通，不作台词成立判据。

## 六、误用信号

- 每场都填了两侧问题，但答案是同一句话换主语。
- 为了"欲望靠近"删掉本来有效的争吵。
- 人物声音只剩“敏感、要强”，或一个人物永远反问、每位母亲永远谈食物。
- 为了自然强制“嗯、那个”、断句、改口、误会、打断或日常小动作。
- 因为完整回答或长句工整，就判为“作者在说话”；因为字面有回应词，就判交流成立。
- 研究人物一天怎么过之后，把研究材料写进台词让人物解释自己的工作。
