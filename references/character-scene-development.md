# 人物可信度、场景吸引力与人物声音

S3b / S3c / S4 共用方法。目标是同时检查两件事："逻辑通但没意思"和"反转惊人但人物不可信"。当前因果链偏重"上一步导致下一步"；本文件补上人物这边和观众这边的问题。

## 一、每场戏的两侧问题

写场景清单或剧本页时，每场至少各答一行（不要求填满表）：

**人物这边**
- 他认为发生了什么？（不是实际发生了什么）
- 为什么选择这种回应，而不是别的？
- 他的选择改变了什么？（关系 / 信息 / 物件归属 / 位置 / 决定）

**观众这边**
- 此刻知道什么？（比人物多还是少）
- 期待什么？
- 看见哪个证据后，会改变对人物的判断？

两侧对不上就是问题所在：人物有依据但观众没期待 → 没意思；观众被惊到但人物没依据 → 不可信。

## 二、叙事方式不止一种

一场戏可以靠下面任一种成立。不要求所有场景都有敌人、秘密或正负翻转；也不把"无冲突"变成新的必须。

| 方式 | 解决的问题 | 作用机制 | 适用边界 | 原始依据 |
|---|---|---|---|---|
| 冲突升级 | 利害清楚、要看人物在压力下怎么选 | 目标 → 阻力 → 尝试 → 代价，每次尝试改变局面 | 每场都升级会让观众疲劳；升级需要新信息，不是提高音量 | 通用编剧法；`causal-chain.md` |
| 欲望靠近 | 关系本身是事件；要看两人怎样一步步允许对方靠近 | 张力来自距离与允许，而非对抗；每一步靠近都有代价或风险 | 需要观众看见"允许"的证据（视线、位置、说法的改变），否则只是慢 | Sciamma 论《燃烧女子的肖像》：写作课教"好场景是冲突"，她以欲望驱动，"没有冲突不等于没有张力" `[第三方转述：Sight & Sound、RogerEbert.com 访谈]` |
| 悬念揭示 | 观众与人物信息不对等 | 先让观众知道或先让人物知道；揭示的时机决定观众的判断怎样改变 | 揭示的东西必须早已在场；临时加进来的秘密是作弊 | L1 信息差、L8 反讽落差（`director-lenses.md`） |
| 关系积累 | 没有单一事件，但两人的相处在变 | 重复动作的细微变化（谁先做、做多久、对谁做）承载变化 | 需要至少一次可见的偏差，否则观众读不到积累 | 母题与重复变义（`stage-3c` 张力六源） |
| 观察与余韵 | 事件已经发生，要看它留下什么 | 让观众停在后果里：空间、物件、人物的日常动作被事件改写 | 时长要配得上；30 秒里余韵通常只能是结尾几秒，不是整段 | L4 画外、出画停留（`stage-5` §5.1d） |

选方式时写一行："这场用 __，因为观众此刻需要 __。"一个故事里可以混用。

## 三、人物可信：不止身份标签

人物可信来自他怎样过一天，不来自小传字数。写人物时至少答：

- 他每天必须做的一件事是什么？做的时候手在干什么？
- 他的钱、住处、作息、交通怎样限制他的选择？（条件比性格更决定行为）
- 这一行 / 这种处境里有哪条外人不知道的规矩？
- 他在这个空间里有权碰什么、不能碰什么？

答不出的是研究缺口，按 `research-to-craft.md` 补，只补会改变本场选择的部分。

## 四、人物声音：四个问题

声音不能只靠口头禅、长短句和语速区分。每个主要人物答：

1. **他习惯注意什么、忽略什么？**（进门先看鞋柜还是先看人；听到价格先算还是先看对方的脸）
2. **面对不同对象，他怎样改变说法？**（对母亲、对上司、对陌生人，同一件事三种说法）
3. **被误解、受辱或被关心时，他怎样保护自己？**（转移到食物 / 反问 / 开玩笑 / 谈钱 / 沉默 / 突然客气）
4. **他听到了哪部分，又故意不回应哪部分？**

这四问决定台词，也决定倾听时的身体。写进 `ip.md` 人物栏或 `02_story.md` 人物段；30 秒任务只答本场用得上的。

## 五、对白审阅：双方有没有真正影响彼此

写完一场台词后检查的是：**后一句是否因为听见了前一句而改变**，而不是每句是否标得出一个及物动词。

| 检查 | 问 | 失败形态 |
|---|---|---|
| 听见了 | 这句里有没有上一句的痕迹（接住、反驳、回避、故意不接其中一部分） | 交错独白：两人各说各的，句子互换位置也成立 |
| 说法变了 | 情绪或对象变化后，这个人的句子结构、用词、长度有没有跟着变 | 全场同一种句法 |
| 保护动作 | 被戳到时，他用的是第 4 节里自己的方式吗 | 每个人被戳到都沉默或都反问 |
| 不回应的部分 | 他跳过的那半句，观众能听出来吗 | 每句都完整回答对方 |
| 情绪时刻 | 峰值处是否允许不连贯、断句、说错 | 峰值处反而最工整 |

Scriptnotes 609（August / Mazin）区分"交错的独白"与真正的对白：对白像魔术贴，两片是为彼此设计的，拆开就没有意义；坏写法是人物只在想自己的下一句；情绪时刻应"更不连贯、更情绪清楚" `[第三方转述]`。本 Skill 采用为审阅问题，不做成句长或标点配额。

及物动词（恳求 / 审问 / 哄）仍可用于节拍表的"策略"列，帮助演员和分镜；它不是台词成立的判据。

## 六、误用信号

- 每场都填了两侧问题，但答案是同一句话换主语。
- 为了"欲望靠近"删掉本来有效的争吵。
- 人物声音四问答成了性格形容词（"敏感"、"要强"）。
- 审阅只数及物动词，不看后一句有没有因为前一句而变。
- 研究人物一天怎么过之后，把研究材料写进台词让人物解释自己的工作。
