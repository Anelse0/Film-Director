# S3a 概念阶段

在写任何场景之前先回答"这东西为什么值得拍、观众会怎样理解它"。产出：选定后的 `01_concept.md`（模板 `templates/concept.md`）。**没有概念卡，不进 S3b。** 候选怎么来见 `concept-generation.md`。

## 3a.0 素材驱动入口

很多项目不是从想法开始，是从一张脸、一个房间、一段音色开始。这时候不要先想故事，先审素材。对每个素材问三句，答案写成可观察的句子：

| 素材 | 三问 |
|---|---|
| 角色图 | 这张脸刚做完什么？它绝不会做什么？它在等谁？ |
| 场景图 | 这个房间在等谁进来？最不该出现在这里的东西是什么？主光源在哪、几点钟？ |
| 音色 | 这个声音会说什么样的谎？它说不出口的一个词是什么？ |
| 动作参考视频 | 这个动作如果发生在错误的地点会怎样？ |

从答案里挑两条互相牵扯的，拼成处境（"这张脸在等人，但这个房间在等别人"）。素材驱动的候选天然带着可拍性，因为主控画面已经在素材里。

## 3a.1 候选的三种失败

写完候选后逐条查：

1. **主题词伪装**："关于失去"不是候选，候选要有人、他在做的事、什么拦着他或什么在向他靠近。
2. **无代价、无变化**："他想留下，但是下雨了"——阻力必须让人物付出可见的代价；靠近型的故事则必须让关系或理解可见地变化，不然只是天气。
3. **落差只在台词里**：期待与结果的落差要发生在行为、事件或观众理解上（先放手的是最想留的人），台词里的机灵话不算。

## 3a.2 主控句（L10）

一句 ≤ 20 字、尽量不用形容词、可以裁决决定的话。测试：拿它去问三个具体问题（这场戏要不要台词？镜头动不动？用不用音乐？），每个问题它都能给出答案才算合格。

- 不合格："关于孤独。"
- 合格："每个人都在等对方先开口。"（→ 台词少；镜头等人；无音乐）

主控句可以在试写或 S3b 之后修订；概念阶段写暂定版即可。

## 3a.3 观众记住什么

回答三问，答不出的回到候选：

1. **画面**：观众三天后还记得的一个画面是什么？
2. **变化**：哪一秒观众对人物的判断变了？（可以是意外，也可以是一个证据让他们重新理解前面看到的）
3. **选择**：角色做了什么可见的选择？（不是感受，是动作）

## 3a.4 反套路否决

下面这些是 AI 视频的默认产物。**出现即需要一行理由**，写不出就换：

| 套路 | 常见形态 |
|---|---|
| 悲伤脸缓推 | 近景 + 缓慢推近 + 泪 |
| 黄金时刻 | 逆光、暖金、镜头光晕 |
| 雨夜霓虹 | 湿地反光、蓝紫光 |
| 对视三十秒 | 两人面对面站着说话，没有物件、没有走位 |
| 背影看远方 | 人物背对镜头望向天际 |
| 慢动作情绪 | 用慢速代替表演 |
| 无来由手持 | 手持晃动但没有视点理由 |
| 万能 bgm | 用音乐补情绪 |
| 空镜开场 | 与人物无关的风景建立镜头 |
| 结尾微笑 | 一切用一个浅笑收束 |

否决不是禁止：〈钥匙〉可以用悲伤脸缓推，如果理由是"这是全片唯一一次镜头主动靠近母亲"。理由要能指回主控句。

## 3a.5 概念模式的交付（在对话里，不是文件）

交付格式见 `concept-generation.md` §交付。规则：

- 候选数量由任务决定（用户已锁定方向可以只发展一个），不固定三个。
- 有 ≥ 2 个候选时，每个候选写"与其他候选的差异"，差异必须在人物选择、事件发展或观众理解上；只换地点不算。
- "这 N 秒拍什么"只写一行画面与变化，防止在概念阶段偷偷做分镜。
- 不写角色小传、不写完整台词、不写镜头。试写片段（≤ 10 行）是例外，用于发现，不当剧本。
- **选定前不落盘。** 用户选定后写 `01_concept.md`：选定候选全文 + 被否候选各一行与否决理由 + 研究记录 + 创作判断。
- 可以推荐；不预选。

## 3a.6 概念卡

模板：`templates/concept.md`。核心字段：创作判断（四行）· 默认地图 · 候选（选定的全文，被否的各一行）· 主控句 · 三问 · 反套路 · 研究记录（缺口 / 材料与来源 / 具体发现 / 可信范围 / 影响哪项决定）· 基调 · 默认透镜倾向（可空）。

选定后跑 `python3 scripts/validate_concept.py 01_concept.md`；ERROR 修，WARN 逐条写理由或补齐。脚本查格式与完整性，不判断创意。
