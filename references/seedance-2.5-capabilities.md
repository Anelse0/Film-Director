## 2. 任务类型与"锁定"规则 `[官方]`

Seedance 2.5 按"传入素材是否锁定输出属性"把任务分为两类：

### 有锁定（素材成为输出时间轴的一部分）

| 任务 | 触发条件 | 锁定内容 | 参数要求 |
|---|---|---|---|
| 视频编辑 | `content.role` = reference_image / reference_video / reference_audio ＋ 提示词含"编辑视频 / 增加 / 加上 / 删除 / 去掉 / 修改 / 替换 / 改成" | 宽高比对齐待编辑视频；时长基本对齐（最大约 0.3s 差异） | `ratio = adaptive`，`duration = -1`，建议 `output_format = mov` |
| 首帧 / 首尾帧 | `content.role` = first_frame / last_frame | 宽高比对齐首帧图 | `ratio = adaptive`；时长可自定义；首尾帧画幅需一致否则尾帧被拉伸 |
| 视频延长 | reference_* role ＋ 提示词含"向前 / 向后延长、延续、续写" | 宽高比对齐待延长视频 | `ratio = adaptive`；时长可自定义；建议 MOV |

多输入视频时由模型根据提示词判定哪一段是待编辑/待延长对象。

### 无锁定（仅语义参考，用户自定 ratio / duration）

- 主体参考（图 / 音视频 / 图＋音色）
- 运动参考（动作 / 表情 / 运镜 / 特效）
- 白模参考 / 渲染（粗粒度、细粒度）
- 风格参考（图 / 视频）
- 音频参考（音乐 / 台词 / 音色）
- 多宫格分镜 / 故事板参考：**不严格对齐分镜图**，只提供大致剧情；≤15 格；推荐火柴人/线稿；分镜图上少写字
- 关键帧参考：**相对严格对齐**；按顺序传入独立图片；Prompt 第一句写"以图片 x 至图片 x 的顺序作为关键帧"
- 一键成片、视频无缝转场、以上能力自由组合

也可用 `reference_image` role 并在 Prompt 中写"图片 1 为首帧 / 图片 3 为首帧，图片 5 为尾帧"——不锁定宽高比，效果相近但不完全匹配。

## 3. 素材数量与稳定性 `[官方]`

| 场景 | 建议 |
|---|---|
| 主体音视频参考 | 1–5 个主体效果好；6–10 稳定性下降需抽卡；单段 5–10s 效果好 |
| 主体图参考 | 1–8 个主体效果好；9–12 需抽卡；≤5 主体单视图/多视图均可；>5 主体建议单视图，多视角拆成多张图而非一张拼图 |
| 宫格分镜 | ≤15 格；18 宫格易静止、顺序错乱 |
| 白模 | 粗粒度（简单几何体）效果好；主体只保留躯体，含四肢/翅膀需补全动作序列；细粒度白模不要含轨迹线/坐标线/相机 cone |
| 视频编辑输入 | ≤20s 效果好 |
| 视频参考图编辑 | 1–5 张参考图效果好；6–8 需抽卡 |
| 延长 | 输入输出均用 MOV；用 2.5 自己生成的视频做延长音量变化更小、衔接更好 |

## 4. Prompt 写作规则

### 4.1 官方结构 `[官方]`

1. **素材指代**：每个图/视频/音频的编号（按上传顺序）与用途（谁是形象、谁是音色、谁是动作、谁是场景）。
2. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。
3. **具体情节**：用时间戳或"镜头 N"切分，逐段写画面、运镜、动作、台词、音效；正向描述。
4. **结尾**：贯穿始终的细节（机位/运镜、环境、声音、氛围）。

### 4.2 素材指代 `[官方]`

- 按上传顺序编号：图 1 / 视频 1 / 音频 1（或 @图片1 / @视频1 / image1 / <video1>，指南内多种写法混用，均可）。
- 每个素材文本绑定；**不建议只在图片里写名字**然后 Prompt 直接用名字——易混淆或重复角色。
- 多主体逐一列清映射；人多用清单。示例："img1-2 是人物 1，对应音频 1；img3-4 是人物 2，对应音频 2"。
- 分工具体到"参考什么"："参考视频 1 中施法的动作，视频 2 的环绕式运镜"；"参考图片 1 的光影和滤镜"。
- 参考素材本身足够精准时只做指代、少复述："严格参考视频 1 的动作与运镜，顺序与视频保持一致"。

### 4.3 时间戳 `[官方]`

- 以 1 秒为单位；写整数秒。
- 区间必须连续："0-3 秒……3-7 秒……7-15 秒" 或 "[1s-4s]…[4s-8s]"；避免"0-3 秒…5-6 秒"这种断裂。
- 支持时间点（"第 5s 快速向左横移转场"）和相对时间（"3 秒后周围的人纷纷摇头"、"按下快门后画面定格 1 秒"）。
- 时段内容太少 → 模型自由发挥；太多 → 过度剪切或剧情遗漏。
- **不要用时间戳控制频次**（"一秒摇头 3 次"）。

### 4.4 负向控制 `[官方]`

- 只支持字幕和音频的负向控制："不要字幕" / "不额外加入对白字幕"；"无 bgm，只生成环境音和动作音" / "不要任何声音"。
- 音频可分维度单独控制：音效、bgm、对白。
- 画面内容不支持负向控制 → 一律正向改写。`[推论]`：第三方 Prompt 中大量的 "No logos, no text, no extra hands" 属于英文平台习惯，效果未经官方确认；本 Skill 只在英文 Prompt 的结尾"约束"段保留少量，且不依赖它。

### 4.5 镜头语言 `[官方]`

- 通识术语可直接写：景别（大全景/全景/中景/近景/特写）、运镜（推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动）、机位（低角度/俯视/第一人称）。
- 热门运镜可直接写：一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、手持镜头、回弹变速。
- 小众术语 → **术语 + 描述性解释**："移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰。"
- 转场写清触发时间与方式："第 5s 快速向左横移转场（向左擦除＋自然叠化）"。

### 4.6 动作与表情 `[官方]`

- 动作优先概括描述（"连续做了几组高抬腿和空翻"），只在有记忆点的动作上写细节；不重复写相同动作。
- 表情写描述性语句，少用成语："津津有味地吃饭" → "脸上带着满足的笑容，大口地吃饭"。

### 4.7 编辑类 `[官方]`

- 明确修改范围与内容，可配时间戳；尽量写 A → B 的过程。
- 示例："仅编辑视频 1 中男人的台词，修改为「你不要过来啊」，口音调整为东北口音"；"把视频 1 中 4-6 秒男人喝咖啡的动作改变为拖地，其余内容不要变化"；"将视频中的人声台词翻译成中文，无字幕，口型做出对应的精准改变，其余均保持不变"。

### 4.8 台词 `[官方示例]` + `[第三方]`

- 官方范例写法：`台词 (老奶奶): "Fly safe, my child. Come back to me."`，逐镜绑定；`[官方]`
- 第三方（fal.ai、runware、rundiffusion）一致做法：台词加双引号；给时间窗；写"她的嘴只在自己台词时动"；在 Prompt 中点明语言；`[第三方]`
- 口型：中文最稳，英文其次，日/韩长句偶有漂移；`[第三方]` 创作者报告
- 多人口型同步与偶发音频失真是 2.0 技术报告承认的未解决问题，2.5 未见官方声明解决；`[第三方]` → 本 Skill 把"多人同框同时说话"列为高风险，默认改为越肩/单人面部＋画外声。`[推论]`

## 5. 第三方经验（有出处，未经官方确认）

| 经验 | 来源 |
|---|---|
| 一整块文本、分段加标签（GLOBAL STYLE / SCENE / CHARACTERS / LOCATION / FIRST FRAME AND BLOCKING / Shot N … Hard cut / OPTICS / PHYSICS / AUDIO）；漏掉某段会以可预测的方式失败；"地点写得模糊是多镜头序列切换后漂移的最常见原因" | Higgsfield 博客 |
| 先写起因再写反应，不要指望模型自行补因果；遮挡后要重复身份与状态；每个参考只赋一个职责并写明"不要复制什么"；把物理动作拆成接触点；台词给时间窗；用上一段末帧作下一段 @Image1 续接；每次只改一个变量 | fal.ai 指南 |
| 主体→动作→镜头→风格；避免"电影感/唯美/震撼"这类空泛形容词；每镜一个主要运镜；音效绑定可见动作；连续性规则写一次并在易漂移的节拍重复；故障对照表（静止画/赶节奏/参考冲突/设计漂移/镜头混乱/音频杂乱/结尾弱） | rundiffusion 指南 |
| 快速动作仍有形变（morphing）；文字渲染只是"减少"而非解决；2.5 对快切密集的 Prompt 抗拒，Prompt 需更长更结构化；30 秒的坏处是第 27 秒出错整段报废 | mindstudio / novoads 评测 |
| 部分平台对人物类生成有审核限制 | rundiffusion |

**冲突记录**：Higgsfield 范例包含"24 个快切"的多角色场景，而评测称 2.5 抗拒快切。本 Skill 采取保守立场：剧情类默认每镜 ≥ 2s、30s 内 ≤ 8 镜；动作类可到 1.5s/镜但标注抽卡风险。`[推论]`

## 6. 本 Skill 的推论与未验证项

- `[推论]` 每个 clip Prompt 必须自足：模型无跨任务记忆。
- `[推论]` 情绪必须外化，模型不执行抽象情绪词。（与官方"少用成语、写描述性语句"一致。）
- `[推论]` 剧情类 30s 内 ≤ 8 镜；台词总时长 ≤ 20s；单句 ≤ 3s。
- `[未验证]` 中文 Prompt 与英文 Prompt 在同一平台上的效果差异；默认跟随台词语言。
- `[未验证]` `Hard cut` 关键字是否被识别为硬切；本 Skill 用官方"镜头 N"分段 + 时间戳表达切点，不依赖该词。
- `[未验证]` 画面负向词（"no logo"）的实际效果。
