# 导演透镜库

透镜是解决具体场景问题的方法，不是导演姓名触发器。保留 L1–L18 编号以兼容旧项目。以下操作是本 Skill 的设计选项 [推论]，不是某位导演的普适命令；采用时说明它解决什么问题，不必每次选主/副两项或做反向表。

## 选择与执行

先明确观众需要看见/听见什么，再确定人物、空间、机位与时间。可选固定、运动、coverage 或长镜，不为新颖改变锁定台词和表演。导演名字用于研究与内部交流；模型正文描述实际画面与声音，热门术语如“希区柯克变焦”不因人名被禁。

| ID / 方法 | 场景问题 | 可操作的选择 | 检查与边界 |
|---|---|---|---|
| L1 信息差 | 紧张从哪里来 | 用前景、插入或声音让观众先知道危险，再看人物接近/避开它 | 不必每镜重写危险，确保观众记得且因果可理解 |
| L2 纵深调度 | 不切镜能否讲清关系 | 人物前后移动、遮挡解除、摇移或焦点转移形成新构图 | 起止位置、走位距离与焦点可执行；不规定中间构图数量 |
| L3 静止的理由 | 哪个变化值得凝视 | 固定镜头突出持续压力或细微推进，必要时小幅靠近 | 可保留联动表演；静止不是反应不足的自动证据 |
| L4 画外 | 省略什么更有力 | 事件在画外，以声音、物件或听者承接 | 不隐藏用户要验证的哭泣高光；延迟时长依据反应 |
| L5 实时与背景 | 环境怎样参与故事 | 前景表演与背景活动在时间/空间上有关系 | 背景不必固定两条，避免抢走关键表演 |
| L6 尺度与沉默 | 人物与环境如何对比 | 远景的渺小与近景细节/声音反差 | 大小、停留、台词数依意图，不固定比例或限一句 |
| L7 几何与冷面 | 秩序与人物是否冲突 | 对称、阵列、常态语气与异常内容并置 | 几何不要求每人无表情或所有动作机械重复 |
| L8 反讽落差 | 期待怎样被改变 | 建立预期，以动作、语言或结果回应/偏离 | 落差须可理解，不限制只能平静反应 |
| L9 视觉喜剧 | 画面或声音怎样制造笑点 | 选择出入画、重复变义、剪辑与音效的时机 | 三拍是选项；语言喜剧同样有效，不设镜数上限 |
| L10 主控意图 | 各部门如何属于同一部片 | 用可裁决的意图协调光、表演、调度随故事发展 | 连贯不等于所有镜头同光、同节奏 |
| L11 镜头并置 | 顺序能否形成含义 | 选择观众看到的信息及其关联，不必每次解释 | 不因为选择并置就删掉用户确认的表演 |
| L12 可演的策略 | 人物在对对方做什么 | 以恳求、试探、回避等目标组织行为 | 目标不一对一映射肌肉动作，纯状态不硬加策略 |
| L13 切点取舍 | 为什么在此切 | 比较情绪、信息、节奏、视线与空间代价 | 可在动作前/中/后切；选错需有具体证据而非配额 |
| L14 视点归属 | 观众跟谁看 | 决定看谁、知道多少、何时转移视点 | 多方反应不等于没有视点，不强制主观镜头 |
| L15 动能分层 | 热烈如何仍可读 | 前中后景运动、机位、色光与声音共同组织能量 | 不填满三层，不用背景运动覆盖主角关键细节 |
| L16 节奏与镜头 | 音乐/动作节拍怎样入镜 | 镜头运动、剪切与重音可以同步，也可形成反差 | 指明实际接点；不把动作频次精确执行当保证 |
| L17 色彩与情节剧 | 怎样容纳外放情绪 | 服装、陈设、色彩、姿态与声音可放大关系 | 大哭和大笑可持续，不强制对称配色或平视机位 |
| L18 群戏 | 多人怎样各有生活 | 决定主交流、次交流与焦点转移；需要时安排重叠对白 | 身份参考按实际人数绑定，非主角也能有台词；多人嘴型另标风险 |

## 从已核实资料到本地决策

- [Lumet / DGA](https://www.dga.org/craft/dgaq/issues/0305-may-2003/under-the-influence-sidney-lumet)：在《Network》中视觉与表演随作品意图变化；排练时连走位、道具一起走。对应 L10 与跨镜连续性，不推导“峰值必须静止”。
- [ASC：Camera Movement](https://theasc.com/article/shot-craft-camera-movement/)：器材/运动从剧本与导演意图出发；推轨能细微调整遮挡，手持并非只有一种幅度；《Jaws》的推轨与变焦是明确的复合动作。对应 L2/L3/L15，不把复合运镜一律判错。
- [Gerwig / DGA](https://www.dga.org/craft/dgaq/issues/1802-spring-2018/gen-next-greta-gerwig)：剧场经验与重叠对白参与创作，并尊重写定台词。对应 L18 与台词保留，不代表模型已解决多人同步。
- 更多人物与台词依据见 `screenwriting-traditions.md` §五。其他透镜保留为本地构图/剪辑工具，不凭旧版姓名归因声称已研究作者完整方法；用户指定某位作者时按所问手法补查第一手资料。

## 误用信号

每个情绪自动选相同透镜；没有需要却多加运镜/道具；把画面左右当作角色永久物理位置；为了套名导标签牺牲台词和可见高光；把稳定性建议写成技术禁令。处理时回到具体镜头，不建立更多禁词表。
