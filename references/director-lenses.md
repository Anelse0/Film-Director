# 导演透镜库

**透镜不是风格，是问题。** 每个透镜来自一位导演反复使用的工作方法，被改写成"它回答场景里的哪个问题"。选透镜的唯一理由是：这场戏正好卡在这个问题上。选完必须写一句"为什么是它"，写不出就不用。

用法（S3b 场景卡 → S5 分镜）：
1. 先写场景的**核心问题**（观众需要知道什么 / 感到什么 / 这场戏最难拍的是什么）。
2. 从下表挑 **1 个主透镜**，最多再加 1 个副透镜。两个透镜必须回答不同的问题。
3. 做**反向测试**：用相反的透镜想 30 秒，写一行"为什么不是它"。
4. 透镜只影响设计，**导演名字永远不进 Prompt**。进 Prompt 的只有可观察量。
5. 相邻两场戏不用同一个主透镜；一个项目里任何透镜出现不超过场景总数的 1/3。

每条透镜的结构：**方法核心 → 它回答的问题 → 转成可观察量 → 误用信号**。

---

## L1 信息差（Hitchcock）

**方法核心**：悬念来自观众比角色知道得多。桌下有炸弹，观众看见了，角色没有。"只要有可能，就让观众知道。"
**它回答的问题**：观众为什么要一直看下去？这场戏的紧张感从哪来？
**转成可观察量**：
- 在场景开头用一个插入镜头或前景细节把"炸弹"给观众看（包里的车票、桌下的手、门缝的影子）。
- 之后每个镜头都让"炸弹"留在画面某处或被声音提醒（钟、脚步、手机震动）。
- 角色的动作离炸弹越来越近但不发现。
- 结尾要么引爆，要么被拿走，不能忘掉它。
**误用信号**：观众知道了但角色的行为没有因此变得可怕或可笑，那只是剧透，不是悬念。

## L2 纵深调度（Spielberg）

**方法核心**：不切镜头，用演员走位、前后景、摇移和焦点转移在一个镜头里完成多个"景别"。调度本身就是潜台词：谁走向谁、谁被推到后景、谁挡住谁。
**它回答的问题**：这场戏的关系变化能不能不用剪辑、只用空间讲清楚？
**转成可观察量**：
- 一个 clip = 一个镜头，写清起点构图和至少 3 个中间构图（"A 从后景走到前景占满画面左半"）。
- 每次构图变化对应一个节拍：走近 = 施压，退后 = 让步，走出焦点 = 被遗忘。
- 焦点转移写成"术语 + 描述"。
- 每个构图停留 ≥ 2 秒。
**误用信号**：人物为了走位而走位，没有节拍对应；或 30 秒里超过 5 次构图变化（模型会乱）。

## L3 静止的理由（Fincher）

**方法核心**：镜头不动，除非有角色层面的理由。动就动得极小、极准，跟着一个眉毛或一次转头。剪掉一切会分散观众的东西。
**它回答的问题**：这场戏哪些东西是多余的？观众的眼睛该停在哪？
**转成可观察量**：
- 默认固定机位。要动的话写触发："当 B 抬头时，镜头才开始 2 秒缓推"。
- 画面里只保留服务当前节拍的物件；其余在【起始状态】里不写。
- 表演减到一个部位的变化：一次眨眼、一次吞咽、手指停住。
- 光只有一个源。
**误用信号**：一切都静止但没有一个"被放大的小动作"，成片像监控录像。

## L4 画外（Haneke）

**方法核心**：不给观众看最暴烈或最痛的那一下。镜头停在别处，声音告诉你发生了什么。观众的想象比画面残酷。
**它回答的问题**：这场戏的高潮直接拍出来会不会廉价？会不会拍不好（模型对暴力、哭泣、拥抱的执行都不稳）？
**转成可观察量**：
- 高潮发生时，镜头固定在一个物件或一个不动的人身上。
- 声音承担事件：关门、碗碎、一声闷响、脚步远去。写清每个声音的秒数。
- 画内人物对画外声音有一个延迟反应（1–2 秒后才动）。
- 高潮后不切近景，保持原景别再停 3 秒。
**误用信号**：画外的事没有可听的声音证据，观众只是不知道发生了什么。

## L5 实时与背景（Cuarón）

**方法核心**：长镜头里时间是真实的，主角在前景，世界在背景自顾自地发生。危险从背景进入前景。
**它回答的问题**：这场戏的世界感从哪来？怎么让环境不是布景？
**转成可观察量**：
- 写 2 条背景动作线（"后景有人推车经过，画左窗外有人影走过"），各给时间点。
- 前景动作与背景动作在某一秒交叉（背景的人进入前景、声音从背景变近）。
- 镜头跟随主角，不切。
- 环境音有层次：近、中、远各一种。
**误用信号**：背景动作太多（> 2 条）或与前景无交叉，模型会把注意力分散成一团。

## L6 尺度与沉默（Villeneuve）

**方法核心**：用巨大的空间压缩人物，然后切到一张不说话的脸，停很久。沉默是主要台词。
**它回答的问题**：这场戏的情绪是不是说不出口的？角色面对的东西是不是比他大？
**转成可观察量**：
- 一个大远景，人物占画面高度 < 1/10，停 ≥ 4 秒。
- 紧接一个面部近景，无台词，只有一个部位变化，停 ≥ 4 秒。
- 声音在两镜之间反差：远景有低频环境音，近景只有呼吸。
- 30 秒内台词 ≤ 1 句。
**误用信号**：空间不够大或脸上没有变化，只剩"慢"。

## L7 几何与冷面（Lanthimos）

**方法核心**：全景、对称、人物摆成几何阵列；台词以零情绪念出；荒诞从"正常的语气说不正常的事"里长出来。
**它回答的问题**：这场戏是不是荒诞的、制度性的、人被规则摆布的？
**转成可观察量**：
- 全景固定，人物位置对称或等距，写清每个人的坐标（画左 1/4、中央、画右 1/4）。
- 面部无表情：写"面部肌肉不动，眨眼频率正常"。
- 台词：正常音量、匀速、无停顿，内容与语气不匹配。
- 动作机械：同样的动作重复两次，间隔相同。
**误用信号**：内容本身就正常，冷面就只是呆。

## L8 反讽落差（Coen 兄弟）

**方法核心**：观众期待的与实际发生的之间有落差；人物说的与意思相反；灾难用最平静的镜头拍。
**它回答的问题**：这场戏的笑点或痛点是不是来自"不该这样但就这样了"？
**转成可观察量**：
- 设一个明确的期待（人物宣布要做什么 / 镜头指向一个方向）。
- 用一个动作打破它（东西没拿到、门打不开、来的不是那个人）。
- 打破后人物的反应比事件小一号（耸肩、继续吃）。
- 镜头不强调：固定，不推。
**误用信号**：落差没有铺垫（期待没建立），只是随机的意外。

## L9 视觉喜剧节奏（Edgar Wright）

**方法核心**：笑点由剪辑、镜头运动、音效和"去而复返"结构制造，不靠台词。看见 → 关上 → 再关一层。
**它回答的问题**：这场戏能不能不靠台词就好笑？
**转成可观察量**：
- 三拍结构写成秒："第 3s 看见，第 4s 关上，第 5s 再关一层"。
- 每个动作有一个对应音效（写清）。
- 用出画/入画代替转场：人物擦过镜头。
- 快切允许到 1.5s/镜，但总镜数 ≤ 10，且标抽卡风险。
**误用信号**：节奏快但没有"预期 → 落空 → 加码"的三拍。

## L10 主控句（Lumet）

**方法核心**：开拍前用一句话回答"这片子讲什么"，之后每个部门的每个决定都以它裁决。
**它回答的问题**：这个项目所有场景为什么属于同一部片？镜头风格怎么统一而不重复？
**转成可观察量**：
- 项目 Bible 顶部写一句主控句（≤ 20 字，不含形容词）。
- 每场戏的视觉方案必须能指回主控句。
- 指不回的手法删掉。
**误用信号**：主控句是主题词（"孤独"）而不是可裁决的句子（"每个人都在等别人先开口"）。

## L11 无表情镜头并置（Mamet）

**方法核心**：从角色目标推出镜头表；每个镜头只提供最少的、不带情绪的信息；意义在镜头之间产生。
**它回答的问题**：这场戏能不能不靠表演、只靠"给观众看什么顺序"讲清楚？
**转成可观察量**：
- 每个镜头写成一句"观众看见 X"，不写情绪。
- 镜头顺序本身构成推理：手 → 门把 → 窗外 → 手松开。
- 全部固定机位、全部无台词也成立时才用。
**误用信号**：镜头之间没有推理关系，只是物件展览。

## L12 可演的动词（Weston）

**方法核心**：不给演员结果（"悲伤一点"），给动词（"恳求他"、"审问她"、"哄她"）。动词可演，情绪不可演。
**它回答的问题**：这一节拍角色到底在对对方做什么？
**转成可观察量**：
- 节拍表"策略"列必须是及物动词 + 对象。
- 每个动词配一个身体证据：恳求 = 身体前倾、手伸出；审问 = 不动、盯住。
- 同一场戏同一角色至少换 2 次动词。
**误用信号**：动词换了但身体证据没换。

## L13 剪辑优先级（Murch）

**方法核心**：一个切点的价值：情绪 > 故事 > 节奏 > 视线 > 二维构图 > 三维空间。为了情绪可以牺牲连戏。
**它回答的问题**：这一刀切在哪？该不该切？
**转成可观察量**：
- 切点落在"情绪变化的瞬间"（眨眼、转头、松手），不落在动作开始前。
- 切前后的视线方向连续（写清画左/画右）。
- 明知违反空间连续但情绪需要时，可以切，写入 QA 风险。
**误用信号**：每一刀都在"动作完成后"，节奏像幻灯片。

## L14 视点归属（Scorsese / Bergman）

**方法核心**：镜头是某个人的意识：主观镜头、被看见的细节、一张脸看另一张脸。观众站在谁的位置上。
**它回答的问题**：这场戏是谁的？观众应该和谁一起不知道？
**转成可观察量**：
- 场景卡写"视点：A"。所有反应镜头拍 A，不拍 B。
- 至少一个 A 的主观镜头（写"从 A 的位置看到……，镜头有轻微手持晃动"）。
- B 的关键动作只在 A 能看到的角度出现。
- 两张脸同框时，写清焦点在谁。
**误用信号**：反应镜头两边平分，视点消失。

## 透镜与场景问题速查

| 场景卡在哪 | 先看 |
|---|---|
| 不紧张 | L1 信息差 |
| 关系变化讲不清 | L2 纵深调度、L12 可演的动词 |
| 太满、太乱 | L3 静止的理由、L11 无表情镜头 |
| 高潮拍不好 / 太廉价 | L4 画外、L6 尺度与沉默 |
| 世界像布景 | L5 实时与背景 |
| 荒诞 / 制度感 | L7 几何与冷面、L8 反讽落差 |
| 不好笑 | L9 视觉喜剧、L8 反讽落差 |
| 各场戏不像一部片 | L10 主控句 |
| 不知道该切在哪 | L13 剪辑优先级 |
| 不知道站谁那边 | L14 视点归属 |
