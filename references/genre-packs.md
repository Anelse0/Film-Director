# 类型包

透镜库（`director-lenses.md`）偏向剧情与喜剧。下面四个类型包补足 Seedance 常见的生产题材。每包结构：**这个类型真正的难题 → 设计规则 → Seedance 执行约束 → 该类型的反套路**。类型包与透镜可叠加，但仍然遵守"一场一个视觉方案"。

## G1 动作 / 打斗

**难题**：观众看不懂谁在哪、谁占上风；模型在快动作上形变。`[第三方]` 快动作 morphing 是已知限制。
**设计规则**：
- 地理先于动作：开场一个镜头交代空间（出口、障碍、武器在哪），之后每镜保持轴线。
- 升级阶梯：每个节拍比上一个多一样东西（多一个人、换一件武器、失去一个出口）。写成 3–5 级。
- 一镜一次接触：每个镜头只有一次碰撞/一次落地/一次抓住，写成"接触 → 结果 → 反应"三句。`[第三方]` fal.ai 把物理动作拆成接触点。
- 代价可见：每次接触留下可观察的痕迹（衣服撕开、瘸、手上血迹用"手上有暗色污渍"写）。
**Seedance 执行约束**：
- 单镜 1.5–3s，30s ≤ 10 镜，标抽卡风险。
- 优先"概括性动作 + 一个记忆点细节"写法。`[官方]` 动作优先概括描述。
- 有动作参考视频时只做指代："严格参考视频1的动作"，不复述。
- 慢动作只在一次接触上用，写清起止秒。
**反套路**：子弹时间、无限弹药、打了 30 秒没人受伤、每镜都在推。

## G2 悬疑 / 恐怖

**难题**：怕的东西一露面就不怕了；模型对怪物、鬼的渲染容易滑稽。
**设计规则**：
- 先声后形：威胁第一次是声音，第二次是影子或局部，第三次才可能露面（或永远不露）。三次各给秒数。
- 负空间：构图里留一块观众以为会出现东西的空白（门口、镜子、窗），至少停 3 秒什么都不发生。
- 角色比观众慢：角色发现威胁比观众晚 2 秒（L1 信息差）。
- 一场只吓一次。
**Seedance 执行约束**：
- 用 L4 画外：威胁在画外，画内只拍反应与物件。
- 光源只有一个，且写它会被什么遮挡（"灯光被走廊尽头的什么东西挡住一秒"）。
- 声音写得比画面细：滴水、地板、呼吸、突然的安静。
**反套路**：jump scare 配巨响、雨夜闪电、镜子里出现脸、手持乱晃。

## G3 UGC / 广告 / 产品

**难题**：一看就是 AI；产品走样；表演像广告。
**设计规则**：
- 真实标记：写 3 个"不完美"（对焦慢半拍、手抖一次、背景有人经过、说话卡壳一次）。`[第三方]` Higgsfield UGC 范例。
- 产品锁：产品只做指代（"图1 是产品，保持形状、颜色、标识位置，不参考图1的背景"），一素材一职责。`[第三方]` fal.ai 产品范例。
- 一个动作证明一个卖点：不说"防漏"，拍"倒过来 2 秒不漏"。
- 台词像自言自语，不像文案：短句、有语气词、可以说一半。
**Seedance 执行约束**：
- 竖版 9:16；手持；单人对镜头；台词时间窗 + 非说话时嘴闭。
- 产品上的文字是风险项，`[第三方]` 文字渲染只"减少"；能用形状和颜色识别就不依赖文字。
- 手持产品的手部动作标抽卡风险。
**反套路**：完美肤质、演播室光、镜头对产品缓推配 bgm、结尾微笑。

## G4 蒙太奇 / 音乐驱动

**难题**：一堆好看的镜头拼在一起没有意义；节奏靠 bgm 硬撑。
**设计规则**：
- 蒙太奇要有论点：一句话写"这组镜头证明什么"（"他每天都在同一个位置等她"）。
- 变量与常量：镜头之间保持一个常量（同一位置 / 同一动作 / 同一物件），只变一个变量（时间 / 天气 / 人数）。
- 匹配剪辑：相邻镜头用形状或动作接（圆 → 圆，转身 → 转身）。写清接点。
- 节奏曲线：镜长单调变化，最后一个镜头最长或最短，不要平均。
**Seedance 执行约束**：
- 有 bgm 时写可见量的音乐描述（"钢琴单音，每 2 秒一下，从第 10s 起加入弦乐"），不写风格名。`[第三方]` rundiffusion：描述变化而非情绪。
- 30s 内 ≤ 8 镜；用关键帧参考（T4）比纯文本更稳。
- 每镜写起止状态，防止"静止画"。
**反套路**：日出延时、人群穿梭、俯拍城市、翻日历。

## 选包规则

- 概念卡的"基调：类型"决定用哪个包；一个项目可以有多个包，但一个 clip 只用一个。
- 类型包不能替代视觉方案；它只告诉你这个类型的难题在哪。
- 类型包里的反套路与 `stage-2a-concept.md` §3a.4 一样是否决表，不是禁止表。
