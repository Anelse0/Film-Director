# S3 故事与场景创作

产出：`02_script/scene-XX.md`（模板 `templates/scene-card.md`）。本阶段允许抽象，这是 **A 层（创作决策）与 B 层（可读说明）**。

## 3.1 先定"这一场为什么存在"

每个场景回答四问，答不出的场景不拍：

1. **谁要什么**（objective）：进场时的具体目标，可完成或失败的那种。"想让她留下"比"想被爱"好。
2. **什么挡着**（obstacle）：另一个人的目标、环境、时间、身体、秘密。
3. **他怎么试**（tactic）：至少两种策略，第一种失败后换第二种。策略是可观察的行为（求、哄、威胁、装作不在乎、转移话题、递东西）。
4. **结束时什么变了**（turn）：关系、信息、物件归属、空间位置、决定。没有变化的场景删掉或并入。

## 3.2 节拍表（Beat Sheet）

把场景切成 4–8 个节拍。每个节拍 = 一次策略尝试及其结果。节拍四步循环：

```
尝试（用一种策略）→ 受阻（对方或环境的反应）→ 调整（换策略）→ 代价（得到了但付出什么 / 没得到）
```

节拍表字段：

| 字段 | 说明 |
|---|---|
| # | 节拍序号 |
| 谁对谁 | 主动方 → 被动方 |
| 策略 | 一个动词短语 |
| 阻力 | 对方怎么挡 |
| 结果 | 成功 / 失败 / 部分 |
| 观众此刻知道 | 信息状态（用于潜台词与反应镜头） |
| 估时 | 秒（对白 3–5 / 动作 2–4 / 静默 2–3） |

估时总和 → 决定 clip 数（见 S2 §2.3）。

## 3.3 空间即戏剧

Seedance 只能拍"空间里发生的事"。所以在 S3 就要定：

- **入口与出口**：谁从哪进、从哪出。进出画是最便宜也最可靠的节拍标记。
- **距离曲线**：两人在场景开始 / 中段 / 结束时的距离（远 → 近 → 远，或近 → 远）。距离变化 = 关系变化，模型执行得很稳。
- **物件**：一个可以被递、被拒、被放下、被拿走的东西。物件的归属变化是最可观察的"转折"。
- **光源与时刻**：一个主光源（窗、灯、火、路灯），定方向。多镜头一致性靠它。
- **声音环境**：这个空间本来有什么声音（雨、街、风扇、人群）。它是 Prompt 的"贯穿细节"。

## 3.4 世界观约束下写

从 `01_bible/world.md` 取三条硬约束写在场景卡顶部（例如"没有电"、"不能直视贵族"、"雨季"）。每个节拍检查不违反。

## 3.5 常见错误

- 场景只有情绪没有目标 → 模型会生成两个人对视 30 秒。
- 转折发生在台词里而不是行为里 → 观众看不到。把"我不走了"改成"把车钥匙放回桌上"。
- 节拍过多 → 30s 里塞 12 个节拍会被模型压缩或遗漏。`[官方]` 时段内容过多导致过度剪切。
- 没有物件、没有距离变化、没有进出画 → 分镜阶段无东西可拍。
