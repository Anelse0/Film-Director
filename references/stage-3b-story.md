# S3b 故事开发

输入：选定的概念（`01_concept.md`）。输出：故事文档，先在对话里交付，用户确认后写 `02_story.md`（模板 `templates/story.md`）。**这是概念与剧本之间缺失的那一层**：概念说"为什么值得拍"，故事文档说"拍什么、谁、按什么顺序、情绪怎么走"。剧本（S3c）才写台词。

用户明确说"一个 clip 就行 / 只要一场戏"时，S3b 与 S3c 合并为一张场景剧本，只停一次；否则 S3b 结束必停。

## 3b.0 参数卡

先从需求提取六参数（`scene-parameters.md` §一），写在故事文档第一行并在停靠交付时回显。多场戏时每场一张，相邻场景按叙事需要延续或改变，不为参数差异改动表演。

## 3b.1 先选主传统与结构

读 `screenwriting-traditions.md`，按人物、处境和目标选方法并写明理由，不以地区/格式套固定结构。

以下是剧情结构参考，不是表演时间模板；具体节拍数与高光位置由内容决定：

| 格式 | 结构 | 节拍数 |
|---|---|---|
| 30 秒先导 / 单场 | 根据进场状态与目标末态选择必要事件，不自动套铺/爆/骤低 | 按事件估时 |
| 60–120 秒短剧单集 | 按人物问题组织进展、转折或未决后果 | 按事件估时 |
| 3–8 分钟短片 | 可选完整因果弧或处境探索 | 按事件估时 |
| 多集 | 本集回答什么、留下什么；检查跨集人物持续性 | 按内容 |

## 3b.2 世界观（只写会改变人物选择的部分）

- **本故事涉及的既定规则**，例如："没有电"、"每天 18 点宵禁"、"探视名单只认直系亲属"。沿用用户世界观，不限制条数。
- **虚构前提**（科幻 / 奇幻 / 架空才写）：规则及其后果，检查内在一致性，不限制只有一条反事实。
- **条件**：主角每月挣多少、住哪、几点起床、靠什么交通。这些比"性格"更决定行为。
- **视觉与声音总则**：媒介、主光的性格、色调、这个世界常有的声音、有无音乐。全是可见可听量。
- 测试：删掉任一条世界观元素，是否有某个人物的某个决定会变？不变的删。

## 3b.3 人物（六格）

每个主要人物：

| 格 | 写法 |
|---|---|
| 想要 | 这个故事里能完成或失败的具体目标 |
| 需要 | 他不知道自己需要的东西（可以与想要冲突） |
| 缺陷 | 让他自己挡自己的那个习惯 |
| 旧伤 | 一件过去的事，一句话，不解释 |
| 秘密 | 他对谁瞒着什么（可空；不为填表虚构） |
| 绝不会做 | 高潮就是他做了这件事，或者最终没做 |

外加：按需记录可观察外观锁、声音表与有作用的身体习惯，不凑字数或动作数。
双人戏：写"两种活法"——两个人各自认为怎么活是对的，故事是这场争论，输赢不重要，代价要可见。
30 秒任务只补会影响本场的字段，已有设定不重编，不强迫角色有秘密。

## 3b.4 情绪温度表

每场一行：场号 / 进场温度 / 出场温度 / 变化原因（一个事件）。温度用 冷 · 温 · 灼 三档或 0–10。规则：
- 温度可连续升降或保持平台，检查变化是否有内容支撑，不强迫升后必降。
- 峰值位置与形态由目标决定，可在结尾持续，不自动骤低或收束。
- 情绪强度与克制独立，详见 `emotion-performance.md`。

## 3b.5 场景清单

每场一行，字段固定：

```
| # | 因果（上一场的转折如何导致本场） | 地点 / 时刻 | 谁 | 实际问题（能用手做的） | 阻力 | 转折（前面的事原来是什么） | 价值变化（+→− / −→+） | 温度 | 物件 | 一句话画面 |
```

规则：
- 记录场景间的因果、对比或并行关系；后场不依赖前场不等于错误，检查其叙事作用。
- 每场必须有"实际问题"，不是"和解"、"面对"。
- 记录实际价值变化；持续积累的场景不为凑转折强行翻转正负。
- 转折写"重新定义"，不写"更大的事"。
- 物件：有叙事作用时记录，不为填表给每场强配一个。
- 一句话画面：观众记住什么；重复可以形成母题，不按出现次数重写。
- 场数由叙事需要与时长承载决定。

## 3b.6 停靠交付（对话内）

```
主传统：__（借：__，因为 __）
一句话故事（目标、处境与事件）：
本故事涉及的世界观规则：
人物（每人两行：想要 / 绝不会做）：
情绪温度表（一行一场）：
场景清单（上表）：
问题：按此写剧本？（或：改哪一场）
```

用户确认后写 `02_story.md` 与 IP 级 `ip.md`（世界观、人物总表、视觉声音总则，跨故事共享；已有则合并不覆盖）。

## 3b.7 常见失败

| 现象 | 处理 |
|---|---|
| 场景清单每场都是"两人谈话" | 回 3b.5 补实际问题与物件 |
| 温度表单调上升但事件没有推进 | 检查事件；有意持续升温可以保留 |
| 高潮没有人物依据 | 回到目标与事件，不为填表虚构禁忌 |
| 世界观堆砌而不影响本场 | 保留影响选择、可信度与连续性的部分 |
| 事件超过时间承载 | 减少无关节点，保留关键事件与高光 |
