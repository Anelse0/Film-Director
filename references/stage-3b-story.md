# S3b 故事开发

输入：选定的概念（`01_concept.md`，含创作判断）。输出：故事文档，先在对话里交付，用户确认后写 `02_story.md`（模板 `templates/story.md`）。**这是概念与剧本之间的一层**：概念说"为什么值得拍、观众会怎样理解"，故事文档说"拍什么、谁、按什么顺序、观众的理解怎样变化"。剧本（S3c）才写台词。

用户明确说"一个 clip 就行 / 只要一场戏"时，S3b 与 S3c 合并为一张场景剧本，只停一次；否则 S3b 结束必停。

共用方法：`character-scene-development.md`（两侧问题、叙事方式、人物可信、人物声音）· `research-to-craft.md`（缺口驱动研究）· `creative-loop.md`（回流与重写）· `causal-chain.md`。

## 3b.0 参数卡与创作判断回显

先从需求提取六参数（`scene-parameters.md` §一），写在故事文档第一行；同时回显概念卡的创作判断（最初理解 / 最后理解 / 最值得保留 / 锁定与探索）。多场戏时每场一张参数卡，相邻场景按叙事需要延续或改变。

## 3b.1 选方法与结构

读 `screenwriting-traditions.md`，按人物、处境和目标选方法并写明理由，不以地区 / 格式套固定结构。每场戏的叙事方式（冲突升级 / 欲望靠近 / 悬念揭示 / 关系积累 / 观察与余韵）按 `character-scene-development.md` §二选择，一个故事可以混用。

承载量参考，不是表演时间模板：

| 格式 | 结构 | 节拍数 |
|---|---|---|
| 30 秒先导 / 单场 | 根据进场状态与目标末态选择必要事件，不自动套铺/爆/骤低 | 按事件估时 |
| 60–120 秒短剧单集 | 按人物问题组织进展、转折或未决后果 | 按事件估时 |
| 3–8 分钟短片 | 可选完整因果弧或处境探索 | 按事件估时 |
| 多集 | 本集回答什么、留下什么；检查跨集人物持续性 | 按内容 |

## 3b.2 世界观（只写会改变人物选择的部分）

- **本故事涉及的既定规则**，例如："没有电"、"每天 18 点宵禁"、"探视名单只认直系亲属"。沿用用户世界观。依赖真实制度的规则标明来源类型（真实材料 / 推演 / 虚构），来自概念卡研究记录。
- **虚构前提**（科幻 / 奇幻 / 架空才写）：规则及其后果，检查内在一致性。
- **条件**：主角每月挣多少、住哪、几点起床、靠什么交通。这些比"性格"更决定行为；不知道的是研究缺口。
- **视觉与声音总则**：媒介、主光的性格、色调、这个世界常有的声音、有无音乐。全是可见可听量。
- 测试：删掉任一条世界观元素，是否有某个人物的某个决定会变？不变的删。

## 3b.3 人物

每个主要人物先答"怎样过一天"（`character-scene-development.md` §三），再按需填六格：

| 格 | 写法 |
|---|---|
| 想要 | 这个故事里能完成或失败的具体目标 |
| 需要 | 他不知道自己需要的东西（可以与想要冲突） |
| 缺陷 | 让他自己挡自己的那个习惯 |
| 旧伤 | 一件过去的事，一句话，不解释 |
| 秘密 | 他对谁瞒着什么（可空；不为填表虚构） |
| 绝不会做 | 高潮就是他做了这件事，或者最终没做 |

人物声音按四问（注意什么 / 对谁改说法 / 被戳到怎样保护自己 / 听到哪部分不回应）写，不只写口头禅与句长。外加可观察外观锁与有作用的身体习惯。
双人戏：写"两种活法"——两个人各自认为怎么活是对的，故事是这场争论，输赢不重要，代价要可见。
30 秒任务只补会影响本场的字段，已有设定不重编。用户给定的人物是锁定内容，研究用于让他更可信，不用于推翻。

## 3b.4 情绪温度表

每场一行：场号 / 进场温度 / 出场温度 / 变化原因（一个事件）。温度用 冷 · 温 · 灼 三档或 0–10。温度可连续升降或保持平台；峰值位置与形态由目标决定，可在结尾持续。情绪强度与克制独立，详见 `emotion-performance.md`。

## 3b.5 场景清单

每场一行，字段固定：

```
| # | 因果或关系（与上一场） | 地点 / 时刻 | 谁 | 实际问题（能用手做的） | 阻力或靠近 | 叙事方式 | 变化（关系 / 信息 / 理解 / 位置） | 温度 | 物件 | 一句话画面 |
```

每场表下补两行（可以很短）：
```
人物侧：他认为发生了什么 → 为什么这样回应
观众侧：此刻知道 __ → 期待 __ → 看见 __ 后改变判断
```

规则：
- 记录场景间的因果、对比或并行关系；后场不依赖前场不等于错误，检查其叙事作用。
- 每场必须有"实际问题"，不是"和解"、"面对"。
- "变化"写这场结束时什么不一样了；持续积累的场景不为凑转折强行翻转正负。
- 叙事方式写一个词加一行理由（"靠近，因为观众此刻需要看见她第一次允许"）。
- 物件：有叙事作用时记录，不为填表给每场强配一个。
- 一句话画面：观众记住什么；重复可以形成母题。
- 场数由叙事需要与时长承载决定。

## 3b.6 停靠交付（对话内）

```
参数 · 创作判断回显：（一行）
方法：__（用于解决 __）
一句话故事（目标、处境与事件）：
本故事涉及的世界观规则（标来源类型）：
人物（每人：怎样过一天一行 / 想要 / 绝不会做 / 声音四问里最有用的一条）：
情绪温度表（一行一场）：
场景清单（上表 + 每场两侧两行）：
最初吸引人的东西还在吗：一行（指回概念卡"独特之处"）
问题：按此写剧本？（或：改哪一场）
```

用户确认后写 `02_story.md` 与 IP 级 `ip.md`（世界观、人物总表、视觉声音总则，跨故事共享；已有则合并不覆盖）。

## 3b.7 常见失败

| 现象 | 处理 |
|---|---|
| 场景清单每场都是"两人谈话" | 回 3b.5 补实际问题与物件 |
| 每场都是对抗 | 检查是否有一场可以用靠近 / 揭示 / 积累 / 余韵 |
| 观众侧每场都写"期待和解" | 观众期待没有被具体建立；回到证据 |
| 温度表单调上升但事件没有推进 | 检查事件；有意持续升温可以保留 |
| 高潮没有人物依据 | 回到"他认为发生了什么 / 为什么这样回应"；缺材料补研究 |
| 世界观堆砌而不影响本场 | 保留影响选择、可信度与连续性的部分 |
| 事件超过时间承载 | 减少无关节点，保留关键事件与高光 |
| 概念里最吸引人的点在故事里消失 | 回 S3a 创作判断，找回它落在哪一场 |
