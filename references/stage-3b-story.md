# S3b 故事开发

输入：选定的概念（`01_concept.md`）。输出：故事文档，先在对话里交付，用户确认后写 `02_story.md`（模板 `templates/story.md`）。**这是概念与剧本之间缺失的那一层**：概念说"为什么值得拍"，故事文档说"拍什么、谁、按什么顺序、情绪怎么走"。剧本（S3c）才写台词。

用户明确说"一个 clip 就行 / 只要一场戏"时，S3b 与 S3c 合并为一张场景剧本，只停一次；否则 S3b 结束必停。

## 3b.0 参数卡

先从需求提取六参数（`scene-parameters.md` §一），写在故事文档第一行并在停靠交付时回显。多场戏时每场一张，相邻两场至少变一项。

## 3b.1 先选主传统与结构

读 `screenwriting-traditions.md` §二，按格式与情绪核心选一个主传统，最多借另一传统的一个元素，各写一句为什么。写进故事文档第一行。

结构按格式取一种，不混：

| 格式 | 结构 | 节拍数 |
|---|---|---|
| 30 秒先导 / 单场 | 按参数卡"进场温度"取曲线（`scene-parameters.md` §二 结构）：冷 = 铺 / 爆 / 切断；灼 = 已在一级 / 二级 + 打断 / 三级 + 低打击 / 骤低 / 切断 | 3–5 |
| 60–120 秒短剧单集 | 3 秒钩 → 每 15 秒一个道具 / 反转 / 台词高点 → 结尾勾 | 4–8 |
| 3–8 分钟短片 | 起承转结（转 = 重新定义）或三幕（催化 / 中点 / 全失 / 终局） | 8–12 |
| 多集 | 每集一张"钩子表"（本集问题 / 结尾切断点 / 下集回答什么）+ 关系网变化 | 每集 4–8 |

## 3b.2 世界观（只写会改变人物选择的部分）

- **三条硬规则**，可拍的："没有电"、"每天 18 点宵禁"、"探视名单只认直系亲属"。每场戏检查不违反。
- **一个大谎**（科幻 / 奇幻 / 架空才写）：唯一的反事实规则 + 它的代价 + 代价在哪一场被支付。其余全按现实。
- **条件**（欧洲写法）：主角每月挣多少、住哪、几点起床、靠什么交通。这些比"性格"更决定行为。
- **视觉与声音总则**：媒介、主光的性格、色调、这个世界常有的声音、有无音乐。全是可见可听量。
- 测试：删掉任一条世界观元素，是否有某个人物的某个决定会变？不变的删。

## 3b.3 人物（六格）

每个主要人物：

| 格 | 写法 |
|---|---|
| 想要 | 这个故事里能完成或失败的具体目标 |
| 需要 | 他不知道自己需要的东西（可以与想要冲突） |
| 缺陷 | 让他自己挡自己的那个习惯 |
| 旧伤 | 一件过去的事，一句话，不解释 |
| 秘密 | 他对谁瞒着什么（韩国写法：对三个人的三个谎） |
| 绝不会做 | 高潮就是他做了这件事，或者最终没做 |

外加：外观锁（≤ 40 字可观察）、声音表（词汇偏好 / 句长 / 口头禅 / 绝不说的词 / 语域）、两个身体习惯。
双人戏：写"两种活法"——两个人各自认为怎么活是对的，故事是这场争论，输赢不重要，代价要可见。
30 秒先导只填：想要、秘密、绝不会做、外观锁、声音表。

## 3b.4 情绪温度表

每场一行：场号 / 进场温度 / 出场温度 / 变化原因（一个事件）。温度用 冷 · 温 · 灼 三档或 0–10。规则：
- 相邻两场方向相反（升后必降），否则观众麻木。
- 全片最高温出现在倒数第二场或最后一场的前 2/3。
- 30 秒先导：曲线由进场温度决定（`scene-parameters.md`）；强度高的戏峰值是骤低，不是最高温。

## 3b.5 场景清单

每场一行，字段固定：

```
| # | 地点 / 时刻 | 谁 | 实际问题（能用手做的） | 阻力 | 转折（前面的事原来是什么） | 价值变化（+→− / −→+） | 温度 | 物件 | 一句话画面 |
```

规则：
- 每场必须有"实际问题"，不是"和解"、"面对"。
- 每场改变一个价值的正负。
- 转折写"重新定义"，不写"更大的事"。
- 物件：能被递、拒、放下、拿走的东西，一场一个。
- 一句话画面：观众记住的那一帧。三场以上画面重复（同一物件同一动作）→ 重写。
- 场数由 3b.1 的节拍数决定；先导 1 场。

## 3b.6 停靠交付（对话内）

```
主传统：__（借：__，因为 __）
一句话故事（含"但是"）：
世界观三条硬规则：
人物（每人两行：想要 / 绝不会做）：
情绪温度表（一行一场）：
场景清单（上表）：
问题：按此写剧本？（或：改哪一场）
```

用户确认后写 `02_story.md` 与 IP 级 `ip.md`（世界观、人物总表、视觉声音总则，跨故事共享；已有则合并不覆盖）。

## 3b.7 常见失败

| 现象 | 处理 |
|---|---|
| 场景清单每场都是"两人谈话" | 回 3b.5 补实际问题与物件 |
| 温度表单调上升 | 插一场降温或改变方向 |
| 人物"绝不会做"空着 | 高潮无处落，必填 |
| 世界观写了一页没人违反 | 只留三条 |
| 30 秒先导写了三幕 | 改成铺 / 爆 / 切断 |
