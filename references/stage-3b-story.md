# S3b 故事开发

输入：选定的概念（`01_concept.md`，含创作判断），或用户带来的想法、人物、片段（`stage-1-intake.md` §2.2 按成熟度进入）。输出：**可连续阅读的故事正文**，先在对话里交付，用户确认后写 `02_story.md`（模板 `templates/story.md`）。故事组织人物、关系、事件与观众理解；可借关键场景试写发现人物，再回流故事，不把探索片段当成已确认剧本。

停靠式默认在故事交付后停一次等确认；用户明确说"一个 clip 就行 / 只要一场戏"时，S3b 与 S3c 合并为一张场景剧本，只停一次。用户带来的成熟故事不重停（`stage-1-intake.md` §2.2）。

共用方法：`character-scene-development.md`（两侧问题、叙事方式、人物可信、人物声音）· `research-to-craft.md`（缺口驱动研究）· `creative-loop.md`（回流与重写）· `causal-chain.md`。

## 3b.0 参数卡与创作判断回显

从需求提取本次有用的参数（`scene-parameters.md` §一），简短回显概念卡的创作判断与锁定项。多场戏只记录相关参数及其变化，不把六项补齐作为开写门槛。

## 3b.1 故事正文优先，辅助表按需

故事阶段先交付一段能从头读到尾的故事：谁、在什么处境里、发生了什么、人物怎样回应、最后怎样。读者不看任何分析说明，也能理解人物、感受到进展，并能指出哪几段有吸引力。这是本阶段的验收，不是场景表填满。

- **短片可以围绕一个完整时刻成立**：30 秒可以是一次交锋、一次允许、一个决定；它需要的是进场状态、变化与末态，不是三幕。
- **较长故事需要承接和发展**：后面的事因为前面的事而变得可能或不再可能；人物在后面的场里带着前面的结果。
- **不能冒充完整**：增加场数、让温度表起伏、拉长字数，都不等于故事完整。完整的标志是读者能说出"为什么会走到这里"和"为什么在这里结束"。
- **辅助表按需**：场景清单（§3b.5）用于定位因果、时间或关系问题，多场戏或多人物时有用；情绪温度表（§3b.4）用于检查表演承载；单场或单一时刻的故事可以都不写。表格服务正文，不替代正文。

## 3b.2 事件与叙事组织：四个判断

写完正文后（或写不顺时），分别判断下面四件事。它们是诊断问题，不是结构模板；不强制倒叙、三幕或最后反转。

| 判断 | 问什么 | 常见失败 |
|---|---|---|
| 事情为什么发生，人物为什么这样做 | 每个关键事件能否从人物所知、所要与处境推出；回应是这个人的回应，还是作者需要的回应 | 事件为了到达结尾而发生；人物忽然坦白或忽然明白 |
| 前面的事怎样影响后面的可能性 | 前一场之后，哪些选择变得可能、哪些不再可能；人物是否带着结果进入下一场 | 场与场只是"接着发生"，互换顺序也无损 |
| 观众何时知道什么 | 观众在每个点上比人物知道得多还是少；某件事让观众早知道、晚知道或同时知道，各自改变什么 | 观众早就猜到结尾却还要等；关键信息在最后一秒才给，前面的场因此没有张力 |
| 结尾为何在这个故事中成立 | 结尾是前面所有选择的后果，还是一个可以安在任何故事上的收束；它回答了故事提出的问题，还是回避了 | 万能结尾（拥抱 / 微笑 / 空镜）；总结主题的金句代替人物的最后一个选择 |

事件顺序与呈现顺序可以分别设计：先按事件发生的顺序核对因果，再决定观众按什么顺序看见。Greta Gerwig 谈《小妇人》时讨论过时间组织怎样改变观众对同一事件的理解与情感 `[第三方转述]`（`screenwriting-traditions.md` §五）；值得吸收的是"观众何时知道什么"的判断能力，不是复制双时间线。

## 3b.3 选方法与结构（按需）

读 `screenwriting-traditions.md`，按人物、处境和目标选方法并写明理由，不以地区 / 格式套固定结构。每场戏的叙事方式（冲突升级 / 欲望靠近 / 悬念揭示 / 关系积累 / 观察与余韵）按 `character-scene-development.md` §二选择，一个故事可以混用。

承载量参考，不是表演时间模板：

| 格式 | 结构 | 节拍数 |
|---|---|---|
| 30 秒先导 / 单场 | 根据进场状态与目标末态选择必要事件，不自动套铺/爆/骤低 | 按事件估时 |
| 60–120 秒短剧单集 | 按人物问题组织进展、转折或未决后果 | 按事件估时 |
| 3–8 分钟短片 | 可选完整因果弧或处境探索 | 按事件估时 |
| 多集 | 本集回答什么、留下什么；检查跨集人物持续性 | 按内容 |

## 3b.3b 世界观（只写会改变人物选择的部分）

- **本故事涉及的既定规则**，例如："没有电"、"每天 18 点宵禁"、"探视名单只认直系亲属"。沿用用户世界观。依赖真实制度的规则标明来源类型（真实材料 / 推演 / 虚构），来自概念卡研究记录。
- **虚构前提**（科幻 / 奇幻 / 架空才写）：规则及其后果，检查内在一致性。
- **条件**：主角每月挣多少、住哪、几点起床、靠什么交通。这些比"性格"更决定行为；不知道的是研究缺口。
- **视觉与声音总则**：媒介、主光的性格、色调、这个世界常有的声音、有无音乐。全是可见可听量。
- 测试：删掉任一条世界观元素，是否有某个人物的某个决定会变？不变的删。

## 3b.3c 人物

已有设定先沿用；需要补足人物依据时，按 `character-scene-development.md` §三查相关生活条件，六格只取有用的部分：

| 格 | 写法 |
|---|---|
| 想要 | 这个故事里能完成或失败的具体目标 |
| 需要 | 他不知道自己需要的东西（可以与想要冲突） |
| 缺陷 | 让他自己挡自己的那个习惯 |
| 旧伤 | 一件过去的事，一句话，不解释 |
| 秘密 | 他对谁瞒着什么（可空；不为填表虚构） |
| 绝不会做 | 区分用户硬锁与人物自我认知；后者可探索，高潮不必围绕打破禁忌 |

人物声音统一按 `character-scene-development.md` §四：生活语言基础、面对对象的调整、当前状态，不为人物指定永久回避方式。外加可观察外观锁与有作用的身体习惯。
双人戏可以是价值争论，也可以合作、陪伴或共同处理一件事；只有价值差异确实影响选择时，才写“两种活法”。
30 秒任务只补会影响本场的字段，已有设定不重编。用户给定的人物是锁定内容，研究用于让他更可信，不用于推翻。

## 3b.4 情绪温度表（按需）

需要检查表演承载或多场起伏时写，每场一行：场号 / 进场温度 / 出场温度 / 变化原因（一个事件）。温度用 冷 · 温 · 灼 三档或 0–10。温度起伏不是完整性的证据。温度可连续升降或保持平台；峰值位置与形态由目标决定，可在结尾持续。情绪强度与克制独立，详见 `emotion-performance.md`。

## 3b.5 场景清单（按需）

需要定位因果、时间或关系问题时写；每场一行，字段按需（物件、温度等没有叙事作用时留空）：

```
| # | 因果或关系（与上一场） | 地点 / 时刻 | 谁 | 本场交流或行动的处境 | 阻力或靠近 | 叙事方式 | 变化或持续（关系 / 信息 / 理解 / 位置） | 温度 | 物件 | 一句话画面 |
```

每场表下补两行（可以很短）：
```
人物侧：他认为发生了什么 → 为什么这样回应
观众侧：此刻知道 __ → 期待 __ → 看见 __ 后改变判断
```

规则：
- 记录场景间的因果、对比或并行关系；后场不依赖前场不等于错误，检查其叙事作用。
- 说清本场在交流或做什么，而不只写“和解”“面对”；交流本身可以是事件，不要求能用手完成。
- "变化"写这场结束时什么不一样了；持续积累的场景不为凑转折强行翻转正负。
- 叙事方式写一个词加一行理由（"靠近，因为观众此刻需要看见她第一次允许"）。
- 物件：有叙事作用时记录，不为填表给每场强配一个。
- 一句话画面：观众记住什么；重复可以形成母题。
- 场数由叙事需要与时长承载决定。

## 3b.7 常见失败

| 现象 | 处理 |
|---|---|
| 场景清单只写"两人谈话"，读不出具体内容 | 补交流处境与观众关心的事；若对话已成立，不为可拍性强加物件或走位 |
| 每场都是对抗 | 检查是否有一场可以用靠近 / 揭示 / 积累 / 余韵 |
| 观众侧每场都写"期待和解" | 观众期待没有被具体建立；回到证据 |
| 温度表单调上升但事件没有推进 | 检查事件；有意持续升温可以保留 |
| 高潮没有人物依据 | 回到"他认为发生了什么 / 为什么这样回应"；缺材料补研究 |
| 世界观堆砌而不影响本场 | 保留影响选择、可信度与连续性的部分 |
| 事件超过时间承载 | 减少无关节点，保留关键事件与高光 |
| 故事靠加场、加温度起伏、加字数显得完整 | 回 §3b.1：读者能否说出为什么走到这里、为什么在这里结束 |
| 结尾可以安在任何故事上 | 回 §3b.2 第四问：结尾是前面选择的后果吗 |
| 观众早就知道结局，中间的场没有张力 | 回 §3b.2 第三问：重排观众知道的时机，不必改事件 |
| 概念里最吸引人的点在故事里消失 | 回 S3a 创作判断，找回它落在哪一场 |
