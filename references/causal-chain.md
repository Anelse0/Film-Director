# 因果诊断：需要时追查，不逐句预排

本文件用于剧情创作，防止特征齐全但前后无因果。纯表演、原文调用和稳定状态测试不强制剧情链，按 `emotion-performance.md` 检查状态延续、变化和末态；无需编造对手、道具或前史。

## 一、为什么会"为了写而写"

规则表列出了阶梯、打断、回声、反讽等特征。把它们当清单填满，会使人物为展示手法而说话。特征是可能的结果，不是原因。回应依据可以来自前句、较早的谈话、共同经历、当前环境或有意保持的状态，不只来自紧邻上一句。

## 二、链的写法（出现逻辑缺口时）

剧情复杂或需要追查逻辑时，可用下面的一行记录；格式不代替因果判断：

```
[N] 上一步对他做了什么 → 他此刻要什么 → 所以他（说 / 做）____ → 这对对方做了什么
```

适用范围：

| 层 | 单元 | 链 |
|---|---|---|
| 概念（S3a） | 候选 | 入口（人物 / 处境 / 规则 / 素材）→ 人物想要什么或什么在向他靠近 → 什么拦着或什么改变了 → **主控画面是这一步的后果** → 观众对人物的理解怎样变化 |
| 故事（S3b） | 场景 | 上一场的转折 → 本场的实际问题 → 阻力 → 转折 → 下一场因此发生什么 |
| 剧本（S3c） | 连续交流片段 | 人物所知与误判 → 为什么此刻这样说或做 → 对方怎样理解 → 有什么后果或仍未改变 |
| 分镜（S5） | 镜头 | 上一镜给了观众什么 → 观众现在需要知道什么 → 所以这一镜拍谁、多近 |

可以先试写对白，再追查缺口；链只记录有助诊断的关系，不是逐句写作前置，也不要求人物每次换策略。

## 三、三个测试（写完之后）

| 测试 | 做法 | 不通过 |
|---|---|---|
| **语境测试** | 连同必要的早先交流、环境和所知，看回应是否有依据 | 允许延迟回答、新信息、误判与有意不接；不能因猜不回上一句而删改 |
| **删除测试** | 删掉这句，后面的句子还成立吗 | 若仍成立，再检查是否损失识别性、控制过程、节奏或关系细节；无作用才删 |
| **负载测试** | 连续表达和动作在可用时间里能否完成，复杂内容是否仍可理解 | 多种相关意图可以同句存在；按实际承载审阅，不按标点或动词数拆句 |

候选也可追查画面与人物事件的联系，但观察、重复与持续情绪不必依靠转折才成立。测试是定位线索，不是自动裁决。

## 四、规则表的正确读法

- 硬约束：用户锁定内容、已核实技术限制、素材绑定与时间覆盖、原文/编译保真。创作手法：句长、峰值、结尾、停顿、策略、打断、回声等，按场景选择，不设通用配额。
- 一场戏只选择确有作用的目标项；数量不作为通过门槛，不为凑数增添特征。
- 清单全部打勾 ≠ 场景成立。交付前按具体风险审阅，三测本身也不是生成配额。

## 五、散文梗概是可选诊断工具

可以用短散文说明交流处境，放在导演意图栏。梗概解释不了时回看原片段：可能是人物依据缺失，也可能是梗概抹掉了表演或关系细节。不要为了让梗概顺畅而覆盖有效对白。

## 六、失败样本（诊断示范）

一段暴露语境缺口的台词（诊断示意，不是自然对白模板）：

```
男 "这道划痕是不是你弄的？"          → 起点，成立
女 "是。赔多少？"                     → 回答 + 回避，成立（用钱结掉）
男 "你每次都这样，拿钱就算完了。"     → 被"赔多少"刺到，成立
女 "算？这半年你只会跟我算！"         → 回声，成立
男 "房租，水电——"                     → 列举反驳，成立
女 "房租水电？你是在记账！你以前先问我疼不疼！"  → 可能调用共同经历，但当前材料没有提供理解依据
男 "你走不了。你怕一个人。"           → "走"从哪来的？前面没有人提过走。这句是为了放"低打击"而写
女 "我怕。也爱你。今晚我搬走。"       → 恐惧、爱与决定可并存；需查决定的依据，而非三个句号
她划掉续租单上的名字                  → 结尾动作，但"续租单"第一次出现
```

当前摘录不足以支撑后段的共同经历与搬走决定，应先查完整场景及已有设定。新名词首次出现本身不是错误；缺依据时可以调整铺垫、回应或删除不必要分支，不能擅编旧伤、强制抢账单来制造动作。“走”可由台词、动作或环境引入，不必先摆道具。
