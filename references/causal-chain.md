# 因果链先于产物

本文件是全 Skill 的通用纪律，S3a–S5 都适用。它解决一种特定的失败：**产物满足了所有规则，但没有一句是被上一句引起的。** 规则描述产物长什么样；因果链规定产物怎么被推出来。没有链的产物不交付。

## 一、为什么会"为了写而写"

规则表（参数卡、协议、模板）列出了特征：阶梯、打断、回声、低打击、骤低、反讽、主控画面。模型如果把它们当清单逐项满足，就会得到一段每项都在、但句与句之间没有推动关系的文本。特征是**结果**，不是**原因**。原因只能是：上一个单元对这个人物做了什么，他现在要什么，所以他说 / 做了这个。

## 二、链的写法（写产物之前）

每个单元一行，格式固定：

```
[N] 上一步对他做了什么 → 他此刻要什么 → 所以他（说 / 做）____ → 这对对方做了什么
```

适用范围：

| 层 | 单元 | 链 |
|---|---|---|
| 概念（S3a） | 候选 | 种子 → 情境（规则）→ 人物想要 → 但是（规则挡住）→ **主控画面是"但是"的后果** → 反讽 = 想要与结果的落差 |
| 故事（S3b） | 场景 | 上一场的转折 → 本场的实际问题 → 阻力 → 转折 → 下一场因此发生什么 |
| 剧本（S3c） | 台词 / 动作 | 上一句对他做了什么 → 他现在要什么 → 所以说这句（一个动作）→ 对方听到后 |
| 分镜（S5） | 镜头 | 上一镜给了观众什么 → 观众现在需要知道什么 → 所以这一镜拍谁、多近 |

链写完再写台词。台词是链的最后一列，不是起点。

## 三、三个测试（写完之后）

| 测试 | 做法 | 不通过 |
|---|---|---|
| **遮住测试** | 遮住上一句，只看这句，能猜出上一句大概说了什么吗 | 猜不出 → 这句没有携带上一句的痕迹（回答、反驳、回避、回声、对动作的反应），重写 |
| **删除测试** | 删掉这句，后面的句子还成立吗 | 成立 → 这句是为了写而写，删 |
| **一件事测试** | 这句只做一件事吗（回答 / 反击 / 回避 / 求 / 宣布） | 做了两件以上 → 拆开或删掉一件 |

三测对候选同样适用：遮住"但是"，主控画面还成立吗（成立 = 画面不是后果）；删掉反讽，故事变了吗（没变 = 反讽是装饰）。

## 四、规则表的正确读法

- 参数卡与协议里的项分两类。**硬项**（必须满足）：句长上限、直接情绪句配额上限、副词规则、峰值形态、结尾不和解 / 可见选择、时间戳与素材绑定。**目标项**（允许出现，从中选）：阶梯、打断、回声、低打击、答非所问、沉默、回声、插入镜头。
- **一场戏从目标项里最多选 3 项**作为设计目标，写在剧本页顶部；其余不刻意出现。出现了没有链的目标项，删。
- 清单全部打勾 ≠ 场景成立。交付前用三测，不用清单。

## 五、先散文，后台词

写台词前先用 3–5 句散文讲这场戏："他发现划痕，问是不是她弄的。她立刻问赔多少，因为她想用钱把事情结掉。他被这个反应刺到，因为……"每句散文含"因为"。散文讲不通的，台词一定讲不通。散文进剧本页的"导演意图"栏。

## 六、失败样本（诊断示范）

一段满足全部特征但无因果的台词（已匿名）：

```
男 "这道划痕是不是你弄的？"          → 起点，成立
女 "是。赔多少？"                     → 回答 + 回避，成立（用钱结掉）
男 "你每次都这样，拿钱就算完了。"     → 被"赔多少"刺到，成立
女 "算？这半年你只会跟我算！"         → 回声，成立
男 "房租，水电——"                     → 列举反驳，成立
女 "房租水电？你是在记账！你以前先问我疼不疼！"  → 回声 + 一件新事（"疼不疼"）无前因：谁疼？什么时候疼？
男 "你走不了。你怕一个人。"           → "走"从哪来的？前面没有人提过走。这句是为了放"低打击"而写
女 "我怕。也爱你。今晚我搬走。"       → 三件事；"搬走"承接的是上一句凭空出现的"走"
她划掉续租单上的名字                  → 结尾动作，但"续租单"第一次出现
```

链断在第 6 句：一个没有前因的名词（疼）引入，之后每句都在为规则服务。修法不是改词，是回到第 5 句重写链：他列房租水电 → 她要什么？→ 她要他停止记账 → 所以她做什么（不是说）：把他手里的账单抢过来 → 这对他做了什么 → ……"走"必须由某个动作或物件先引入（行李、门、钥匙），否则不能出现。

## 七、与其他文件的关系

- `scene-parameters.md` §二 的表是取值与允许；本文件规定怎么用它。
- `concept-generation.md` 第 5 步"发展"必须附链。
- `stage-3b-story.md` 场景清单加"因果"列。
- `stage-3c-script.md` §3c.4b 链是剧本页的前置。
- `stage-7-qa-continuity.md` 人工检查加三测。
- `scripts/validate_prompt.py` W19 只能查"一句做多件事"的粗略代理（一句引号内 ≥ 3 个句号 / 叹号 / 问号）；遮住测试与删除测试只能人做。
