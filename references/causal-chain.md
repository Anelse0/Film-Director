# 因果链先于产物

本文件用于剧情创作，防止特征齐全但前后无因果。纯表演、原文调用和稳定状态测试不强制剧情链，按 `emotion-performance.md` 检查状态延续、变化和末态；无需编造对手、道具或前史。

## 一、为什么会"为了写而写"

规则表（参数卡、协议、模板）列出了特征：阶梯、打断、回声、低打击、骤低、反讽、主控画面。模型如果把它们当清单逐项满足，就会得到一段每项都在、但句与句之间没有推动关系的文本。特征是**结果**，不是**原因**。原因只能是：上一个单元对这个人物做了什么，他现在要什么，所以他说 / 做了这个。

## 二、链的写法（写产物之前）

剧情复杂或需要追查逻辑时，可用下面的一行记录；格式不代替因果判断：

```
[N] 上一步对他做了什么 → 他此刻要什么 → 所以他（说 / 做）____ → 这对对方做了什么
```

适用范围：

| 层 | 单元 | 链 |
|---|---|---|
| 概念（S3a） | 候选 | 入口（人物 / 处境 / 规则 / 素材）→ 人物想要什么或什么在向他靠近 → 什么拦着或什么改变了 → **主控画面是这一步的后果** → 观众对人物的理解怎样变化 |
| 故事（S3b） | 场景 | 上一场的转折 → 本场的实际问题 → 阻力 → 转折 → 下一场因此发生什么 |
| 剧本（S3c） | 台词 / 动作 | 上一句对他做了什么 → 他现在要什么 → 所以说这句（一个动作）→ 对方听到后 |
| 分镜（S5） | 镜头 | 上一镜给了观众什么 → 观众现在需要知道什么 → 所以这一镜拍谁、多近 |

链写完再写台词。台词是链的最后一列，不是起点。

## 三、三个测试（写完之后）

| 测试 | 做法 | 不通过 |
|---|---|---|
| **遮住测试** | 遮住上一句，只看这句，能猜出上一句大概说了什么吗 | 检查是否回答、反驳、回避、引入新信息或对动作反应；猜不回上一句不单独构成删改理由 |
| **删除测试** | 删掉这句，后面的句子还成立吗 | 若仍成立，再检查是否损失识别性、控制过程、节奏或关系细节；无作用才删 |
| **一件事测试** | 这句只做一件事吗（回答 / 反击 / 回避 / 求 / 宣布） | 无关任务挤占时间才拆；多部位同步服务同一行为不按标点计数 |

三测对候选同样适用：遮住阻力或靠近的那一步，主控画面还成立吗（成立 = 画面只是插图）；删掉观众理解的变化，故事变了吗（没变 = 变化是装饰）。

## 四、规则表的正确读法

- 硬约束：用户锁定内容、已核实技术限制、素材绑定与时间覆盖、原文/编译保真。创作手法：句长、峰值、结尾、停顿、策略、打断、回声等，按场景选择，不设通用配额。
- 一场戏只选择确有作用的目标项；数量不作为通过门槛，不为凑数增添特征。
- 清单全部打勾 ≠ 场景成立。交付前用三测，不用清单。

## 五、先散文，后台词

写台词前可先用短散文讲这场戏："他发现划痕，问是不是她弄的。她立刻问赔多少，因为她想用钱把事情结掉。他被这个反应刺到，因为……"散文说明前因后果，不要求每句固定出现“因为”。散文讲不通的，台词一定讲不通。散文进剧本页的"导演意图"栏。

## 六、失败样本（诊断示范）

一段满足全部特征但无因果的台词（已匿名）：

```
男 "这道划痕是不是你弄的？"          → 起点，成立
女 "是。赔多少？"                     → 回答 + 回避，成立（用钱结掉）
男 "你每次都这样，拿钱就算完了。"     → 被"赔多少"刺到，成立
女 "算？这半年你只会跟我算！"         → 回声，成立
男 "房租，水电——"                     → 列举反驳，成立
女 "房租水电？你是在记账！你以前先问我疼不疼！"  → 回声 + 一件新事（"疼不疼"）无前因：谁疼？什么时候疼？
男 "你走不了。你怕一个人。"           → "走"从哪来的？前面没有人提过走。这句是为了放"低打击"而写
女 "我怕。也爱你。今晚我搬走。"       → 三件事；"搬走"承接的是上一句凭空出现的"走"
她划掉续租单上的名字                  → 结尾动作，但"续租单"第一次出现
```

链断在第 6 句：一个没有前因的名词（疼）引入，之后每句都在为规则服务。修法不是改词，是回到第 5 句重写链：他列房租水电 → 她要什么？→ 她要他停止记账 → 所以她做什么（不是说）：把他手里的账单抢过来 → 这对他做了什么 → ……“走”需要可理解的语境，可由台词、动作或环境引入，不必先摆道具。
