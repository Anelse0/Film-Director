# S3c 剧本落地

输入：`02_story.md` 的场景清单（含每场两侧两行）。输出：每场一份剧本页，先在对话里交付，用户确认后写 `03_script/scene-XX.md`（模板 `templates/script-scene.md`）。**S3c 结束必停**（单 clip 指示除外，此时与 S3b 合并只停一次）。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

共用方法：`character-scene-development.md` §四 人物声音、§五 对白审阅 · `causal-chain.md` · `creative-loop.md`（重写）· `research-to-craft.md`（行为与台词缺口）。

## 3c.1 一场戏的问题

人物侧：谁要什么（实际问题）· 什么挡着或什么在靠近 · 他怎么试（按阻力选择可观察策略）· 结束时什么变了（关系 / 信息 / 物件归属 / 位置 / 决定）。
观众侧：进场时知道什么、期待什么 · 哪个证据改变他们对人物的判断。
两侧从 `02_story.md` 场景清单继承，剧本页可以修正。

## 3c.2 节拍表

剧情节拍按实际尝试与结果划分，数量由内容和时长决定。可用"尝试 → 受阻 → 调整 → 代价"检查；靠近型场景用"试探 → 允许 / 退回 → 代价"；纯表演测试跳过本阶段。

```
| # | 谁对谁 | 本段交流或行动（策略按需） | 阻力或回应 | 结果或持续状态 | 观众此刻知道 | 落差（若有） | 估时 s |
```

估时以实际台词、动作路径与高光为依据，标明同步与先后；不用平均节拍时长决定镜头。策略列的动词服务演员与分镜，不是台词成立的判据。

## 3c.3 空间即戏剧

按场景需要明确入口/出口、起止位置、相关物件、光与声音。空间是类别名（"医院走廊"）时按 `research-to-craft.md` 补实际陈设与动线。人物关系可以通过距离或表演变化呈现，不强制走位或每场一个道具。

## 3c.4a 从有效入口开发，再检查

可从场景梗概、事件、人物或对白草稿进入。先有一句可信的话也可以；不要先给每句分派策略再让人物填空。依据 `character-scene-development.md` 补确有缺口的交流处境，写出连续片段后审阅。逻辑断裂处再用 `causal-chain.md` 追查，不要求逐句建链。新发现回流故事，不能覆盖用户锁定内容。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
参数：强度 · 方向 · 信息 · 权力 · 进场温度 · 密度（回显）
叙事方式：__，因为观众此刻需要 __
[世界观硬规则本场涉及：…]
动作行：只写看得见的。主语 + 部位 + 动词 + 对象。情绪名称不能替代具体证据；保留速度、幅度和渐变信息。
角色名
    台词。
    （括号补实际有用的表演/声音提示，锁定台词不因格式被改字）
动作行：…
```

动作行应让所选表演可见，例如“她看着他，眼泪积在下眼睑，抬眼忍住”。这只是新编示意；具体通道依场景或原库选定，不因原句抽象便擅加杯子、递物或固定两秒停顿。

## 3c.5 台词

### 场景与交流诊断

统一读 `character-scene-development.md` §四–五。按连续交流片段审阅人物知道什么、为什么此刻这样说、对方如何接收；不要求每句留下上一句的词、不要求每句执行一个及物动词。直接回答、回到早先话题、完整长句和有意重复均可成立。发现问题才定位到具体句子，不把诊断问题变成生成配额。

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接表达、停顿、打断与结尾由场景、角色声音和可用时间决定；场景参数不是固定配额。既有台词锁定，仅在用户要求修改时改写。

### 对白审阅（写完整场之后）
按共用方法检查交流依据、人物声音与可说性。记录有文本证据的问题、保留项和修订代价；不凭“无问题”三字宣布质量通过，也不因全句工整或双方都激动而自动改写。

### 执行信息与空泛描述
- 动作行保留可观察的速度、程度、渐变、持续与控制，不因"逐渐""缓慢"等词而删细节。
- 情绪标签不能代替表演；音量、语速放在"说法"栏。
- 台词自然度由角色与场景审阅，不计副词配额。下表用于决定是否需要补信息，不提供一键替换句式。

| 原句 | 信息作用 | 处理依据 |
|---|---|---|
| "她冷冷地说：随便。" | 态度概括 | 台词保留；需要执行时明确本场已有依据的音量、视线或发声方式，不自动加道具 |
| "他真的真的很想她。" | 内心或对白 | 内心留 A 层；若是台词，重复可能有效，不能机械删字 |
| "他愤怒地摔门。" | 情绪加动作 | 摔门已可见；按场景补力度或结果，不能无依据加灰尘 |
| "她小心翼翼地问……" | 交流态度 | 判断顾虑是什么、对谁说；不强加停顿或“对吧” |
| "他慢慢地走过去。" | 可观察速度 | 保留速度，确需计时时估算距离和时间，不统一改成三秒 |

### 张力六源（可选武器，不是配额）
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡与叙事方式决定哪几源是主武器。

### 每句四件套（需要时）
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，写可观察量）· 听者（视线 / 手 / 身体）。30 秒任务或台词很少时可只对关键句写。

## 3c.6 停靠交付（对话内）

每场：相关参数与叙事方式 + 剧本页全文 + 必要的节拍/估时说明 + 变化或持续状态及观众关注点。简单台词测试不输出全套表。问题：按此进分镜？（或：改哪一句 / 改哪个参数）

用户确认后写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，按共用诊断给出具体证据、可能原因与不确定处；修改需用户要求。

## 3c.7 重写

收到批评后按 `creative-loop.md` §二诊断层级，§三执行：保留上一版、说明改了什么与解决什么、核对失去的细节、定点改、不换故事。示例见该文件 §四。

## 3c.8 常见失败

| 现象 | 处理 |
|---|---|
| 转折只靠一句宣布，缺乏可信依据 | 先查人物为什么改变；直接说出决定可以成立，不自动换成放钥匙 |
| 只有情绪形容，没有可见表现 | 补可观察证据；不按"地"或词性判错 |
| 对视没有戏 | 检查持续压力、变化与目标，有意凝视不强配道具 |
| 台词像同一个人写的 | 查语言经历、交流对象与当前处境；共用日常短句不机械重写 |
| 疑似交错独白 | 查连续片段的回应依据；延迟回应、各执一词也可有意成立，不以句子能换位单独判错 |
| 需求明确要喊出来，却写成沉默对峙 | 具体表达方向被默认覆盖；按需求修正 |
| 每项特征都在，但交流不成立 | 回交流处境查作者安排是否越过人物所知；必要时追查因果 |
| 人物解释制度或工作 | 看听者是否需要知道、人物为何此刻解释；不把合理说明一律当科普删除 |
| 事件超出 30 秒承载 | 保留核心因果与高光，重排同步/先后；不足时拆 clip 或协商 |
| 重写后原稿的有效细节没了 | `creative-loop.md` §三 第 3 条 |
