# S3c 剧本落地

输入：`02_story.md` 的场景清单（含每场两侧两行）。输出：每场一份剧本页，先在对话里交付，用户确认后写 `03_script/scene-XX.md`（模板 `templates/script-scene.md`）。**S3c 结束必停**（单 clip 指示除外，此时与 S3b 合并只停一次）。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

共用方法：`character-scene-development.md` §四 人物声音、§五 对白审阅 · `causal-chain.md` · `creative-loop.md`（重写）· `research-to-craft.md`（行为与台词缺口）。

## 3c.1 一场戏的问题

人物侧：谁要什么（实际问题）· 什么挡着或什么在靠近 · 他怎么试（按阻力选择可观察策略）· 结束时什么变了（关系 / 信息 / 物件归属 / 位置 / 决定）。
观众侧：进场时知道什么、期待什么 · 哪个证据改变他们对人物的判断。
两侧从 `02_story.md` 场景清单继承，剧本页可以修正。

## 3c.2 节拍表

剧情节拍按实际尝试与结果划分，数量由内容和时长决定。可用"尝试 → 受阻 → 调整 → 代价"检查；靠近型场景用"试探 → 允许 / 退回 → 代价"；纯表演测试跳过本阶段。

```
| # | 谁对谁 | 策略（及物动词 + 对象，可演） | 阻力或回应 | 结果 | 观众此刻知道 | 落差（期待 → 结果） | 估时 s |
```

估时以实际台词、动作路径与高光为依据，标明同步与先后；不用平均节拍时长决定镜头。策略列的动词服务演员与分镜，不是台词成立的判据。

## 3c.3 空间即戏剧

按场景需要明确入口/出口、起止位置、相关物件、光与声音。空间是类别名（"医院走廊"）时按 `research-to-craft.md` 补实际陈设与动线。人物关系可以通过距离或表演变化呈现，不强制走位或每场一个道具。

## 3c.4a 先散文，再链，再台词

读 `causal-chain.md`。需要展开剧本逻辑时按下面顺序，不是每次都输出全部中间表：
1. 先散文：3–5 句讲这场戏，讲清前因后果和观众此刻知道什么（进"导演意图"栏）。
2. 可选：三种不同的进入方式各一句，选一种并写为什么（`creative-loop.md` §五）。
3. 再写链：每句台词 / 每个动作一行 `[N] 上一步对他做了什么 → 他此刻要什么 → 所以 ____ → 对方因此 ____`。
4. 写台词（链的最后一列）。潦草版先让人物说话，再决定保留什么。
5. 三测（遮住 / 删除 / 一件事）+ 对白审阅（§3c.5）。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
参数：强度 · 方向 · 信息 · 权力 · 进场温度 · 密度（回显）
叙事方式：__，因为观众此刻需要 __
[世界观硬规则本场涉及：…]
动作行：只写看得见的。主语 + 部位 + 动词 + 对象。情绪名称不能替代具体证据；保留速度、幅度和渐变信息。
角色名
    台词。
    （括号补实际有用的表演/声音提示，锁定台词不因格式被改字）
动作行：…
```

动作行示例：
- ❌ 她伤心地看着他。
- ✅ 她看着他，手指在杯沿上停住，两秒后把杯子推过去。

## 3c.5 台词

### 通用关（任何参数下每句必过）
| 关 | 检验 |
|---|---|
| 可说出口 | 按角色语速读，呼吸与停顿符合意图 |
| 听见了对方 | 这句里有上一句的痕迹：接住、反驳、回避，或故意不接其中一部分 |
| 有作用 | 这句在对对方做什么（求、拒、转移、保护自己、宣布）；标不出来时先看它是否是倾听或保护的反应，仍无作用才删 |
| 不说主题 | 不以作者总结代替人物交流；有动机表达观点时可保留 |
| 是这个人说的 | 对照人物声音四问（注意什么 / 对谁改说法 / 被戳到怎样保护自己 / 不回应哪部分） |

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接表达、停顿、打断与结尾由场景、角色声音和可用时间决定；场景参数不是固定配额。既有台词锁定，仅在用户要求修改时改写。

### 对白审阅（写完整场之后）
按 `character-scene-development.md` §五：检查双方有没有真正影响彼此——后一句是否因为听见前一句而变；情绪或对象变化后说法有没有变；被戳到时用的是不是这个人自己的保护方式；峰值处是否允许不连贯。审阅不数及物动词。

### 执行信息与空泛描述
- 动作行保留可观察的速度、程度、渐变、持续与控制，不因"逐渐""缓慢"等词而删细节。
- 情绪标签不能代替表演；音量、语速放在"说法"栏。
- 台词自然度由角色与场景审阅，不计副词配额。下表是可选改写，不覆盖用户锁定原文。

| 原句 | 副词做的事 | 换成 |
|---|---|---|
| "她冷冷地说：随便。" | 标注态度 | "她说：随便。（停顿 2 秒）她把钥匙推过去。" |
| "他真的真的很想她。" | 加强度 | "他想她。" + 动作行：他把她的杯子洗了，又放回原处。 |
| "他愤怒地摔门。" | 标注情绪 | "他把门摔上，门框上的灰落下来。" |
| "她小心翼翼地问……" | 标注方式 | "她问：……（停顿）……对吧？" |
| "他慢慢地走过去。" | 标注速度 | "他走过去，用了三秒。" |

### 张力六源（可选武器，不是配额）
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡与叙事方式决定哪几源是主武器。

### 每句四件套（需要时）
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，写可观察量）· 听者（视线 / 手 / 身体）。30 秒任务或台词很少时可只对关键句写。

## 3c.6 停靠交付（对话内）

每场：参数与叙事方式一行 + 剧本页全文 + 节拍表 + 一行"这场改变了什么" + 一行"观众此刻对人物的判断变了吗"。问题：按此进分镜？（或：改哪一句 / 改哪个参数）

用户确认后写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，只出 ✅ / ⚠️ 报告，⚠️ 只用通用关与参数关判定，并附对白审阅一行。

## 3c.7 重写

收到批评后按 `creative-loop.md` §二诊断层级，§三执行：保留上一版、说明改了什么与解决什么、核对失去的细节、定点改、不换故事。示例见该文件 §四。

## 3c.8 常见失败

| 现象 | 处理 |
|---|---|
| 转折在台词里 | 改成动作："我不走了" → 把车钥匙放回桌上 |
| 只有情绪形容，没有可见表现 | 补可观察证据；不按"地"或词性判错 |
| 对视没有戏 | 检查持续压力、变化与目标，有意凝视不强配道具 |
| 台词像同一个人写的 | 人物声音四问；共用日常短句不机械重写 |
| 交错独白 | 句子互换位置也成立 → 回链，让后一句带上一句的痕迹 |
| 需求明确要喊出来，却写成沉默对峙 | 具体表达方向被默认覆盖；按需求修正 |
| 每项特征都在，但句与句不推 | 回 §3c.4a 先散文后链，三测 |
| 人物开始解释制度或工作 | 研究材料进了台词；只留影响行为的部分 |
| 事件超出 30 秒承载 | 保留核心因果与高光，重排同步/先后；不足时拆 clip 或协商 |
| 重写后原稿的有效细节没了 | `creative-loop.md` §三 第 3 条 |
