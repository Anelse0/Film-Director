# S3c 剧本落地

输入：`02_story.md` 的场景清单。输出：每场一份剧本页，先在对话里交付，用户确认后写 `03_script/scene-XX.md`（模板 `templates/script-scene.md`）。**S3c 结束必停**（单 clip 指示除外，此时与 S3b 合并只停一次）。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

## 3c.1 一场戏的四问

进场前答不出的场不写：谁要什么（实际问题）· 什么挡着 · 他怎么试（≥ 2 种可观察策略）· 结束时什么变了（关系 / 信息 / 物件归属 / 位置 / 决定）。

## 3c.2 节拍表

4–8 个节拍，每个 = 一次策略尝试及其结果。循环：尝试 → 受阻 → 调整 → 代价。

```
| # | 谁对谁 | 策略（及物动词 + 对象，可演） | 阻力 | 结果 | 观众此刻知道 | 落差（期待 → 结果） | 估时 s |
```

估时：对白节拍 3–5s，动作 2–4s，静默 2–3s。总和 → clip 数（S5 用）。
策略必须是可演动词：恳求、审问、哄、威胁、装作不在乎、转移、递、拒。同一角色一场至少换两次动词。

## 3c.3 空间即戏剧

Seedance 只能拍空间里发生的事。每场写死：入口与出口 · 距离曲线（开始 → 中段 → 结束）· 物件（一场一个）· 主光源与方向 · 声音环境。距离变化 = 关系变化，模型执行最稳。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
参数：强度 · 方向 · 信息 · 权力 · 进场温度 · 密度（回显）
[世界观硬规则本场涉及：…]
动作行：只写看得见的。主语 + 部位 + 动词 + 对象。禁止副词、情绪形容词、成语。
角色名
    台词。
    （允许的括号只有：画外 / 对某人 / 停顿 N 秒 / 语言）
动作行：…
```

动作行示例：
- ❌ 她伤心地看着他。
- ✅ 她看着他，手指在杯沿上停住，两秒后把杯子推过去。

## 3c.5 台词

### 通用关（任何参数下每句必过）
| 关 | 检验 |
|---|---|
| 可说出口 | 大声读，不用换气两次 |
| 有意图 | 这句想让对方做什么（Sorkin）；标不出来的删 |
| 不说主题 | 没有解释故事意义的句子 |
| 是这个人说的 | 换成另一个角色说也成立 → 重写 |

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接情绪句配额、答非所问、打断与回声、升级阶梯、低打击、峰值形态、结尾、沉默——全部按参数卡取值，不用默认值。**强度高 · 外放的戏允许 25 字长句、允许每人一句直接情绪句、要求打断与三级阶梯；内收的戏才用 ≤ 15 字与不解释情绪。** 写台词前先在剧本页顶部回显参数卡。

### 副词规则（全参数通用）
- 动作行零副词、零情绪形容词。
- 括号提示禁止情绪词。音量、语速写在"说法"栏。
- 台词内每句 ≤ 1 个副词，不得是情绪副词。
- 替换表：

| 原句 | 副词做的事 | 换成 |
|---|---|---|
| "她冷冷地说：随便。" | 标注态度 | "她说：随便。（停顿 2 秒）她把钥匙推过去。" |
| "他真的真的很想她。" | 加强度 | "他想她。" + 动作行：他把她的杯子洗了，又放回原处。 |
| "他愤怒地摔门。" | 标注情绪 | "他把门摔上，门框上的灰落下来。" |
| "她小心翼翼地问……" | 标注方式 | "她问：……（停顿）……对吧？" |
| "他慢慢地走过去。" | 标注速度 | "他走过去，用了三秒。" |

### 张力六源
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡决定哪几源是主武器：外放用打断与回声，内收用沉默与动作回答，不对等用权力转移，揭秘用重复变义。

### 角色声音表核对
每句台词换成另一个角色说也成立 → 重写。核对声音表的词汇偏好、句长、绝不说的词。

### 每句四件套
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，禁形容词）· 听者（视线 / 手 / 身体）。

## 3c.6 停靠交付（对话内）

每场：参数回显一行 + 剧本页全文 + 节拍表 + 一行"这场改变了什么"。问题：按此进分镜？（或：改哪一句 / 改哪个参数）

用户确认后写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，只出 ✅ / ⚠️ 报告，⚠️ 只用五关判定。

## 3c.7 常见失败

| 现象 | 处理 |
|---|---|
| 转折在台词里 | 改成动作："我不走了" → 把车钥匙放回桌上 |
| 动作行出现"地" | 副词进来了，换成动作或停顿 |
| 两人对视三十秒 | 回 3c.1 补实际问题与物件 |
| 台词像同一个人写的 | 声音表核对 |
| 需求要吵架，写成了对峙 | 参数卡被缺省覆盖：强度高 · 外放的规则没生效 |
| 12 个节拍塞进 30 秒 | 减到 3 个，或拆 clip |
