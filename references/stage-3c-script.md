# S3c 剧本落地

输入：`02_story.md` 的场景清单。输出：每场一份剧本页，先在对话里交付，用户确认后写 `03_script/scene-XX.md`（模板 `templates/script-scene.md`）。**S3c 结束必停**（单 clip 指示除外，此时与 S3b 合并只停一次）。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

## 3c.1 一场戏的四问

进场前答不出的场不写：谁要什么（实际问题）· 什么挡着 · 他怎么试（按阻力选择可观察策略）· 结束时什么变了（关系 / 信息 / 物件归属 / 位置 / 决定）。

## 3c.2 节拍表

剧情节拍按实际尝试与结果划分，数量由内容和时长决定。可用“尝试 → 受阻 → 调整 → 代价”检查；纯表演测试跳过本阶段，不强制剧情循环。

```
| # | 谁对谁 | 策略（及物动词 + 对象，可演） | 阻力 | 结果 | 观众此刻知道 | 落差（期待 → 结果） | 估时 s |
```

估时：对白节拍 3–5s，动作 2–4s，静默 2–3s。总和 → clip 数（S5 用）。
策略必须是可演动词：恳求、审问、哄、威胁、装作不在乎、转移、递、拒。策略变化应有阻力或目标变化，不设最低转换次数。

## 3c.3 空间即戏剧

按场景需要明确入口/出口、起止位置、相关物件、光与声音。人物关系可以通过距离或表演变化呈现，不强制走位或每场一个道具，也不宣称一种调度最稳。

## 3c.4a 因果链（剧本页之前，必做）

读 `causal-chain.md`。需要展开剧本逻辑时，可按下面顺序工作；不是每次都要输出全部中间表：
1. 先散文：3–5 句讲这场戏，讲清前因后果（进"导演意图"栏）。
2. 再写链：每句台词 / 每个动作一行 `[N] 上一步对他做了什么 → 他此刻要什么 → 所以 ____ → 对方因此 ____`。
3. 从参数卡选本场有用目标，不设置数量配额；不能为凑项添加事件。
4. 写台词（链的最后一列）。
5. 三测：遮住 / 删除 / 一件事。不过的句子回到链。
任何名词（走、搬、疼、账单）第一次出现前，必须已被动作或物件引入。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
参数：强度 · 方向 · 信息 · 权力 · 进场温度 · 密度（回显）
目标项（按需）：
[世界观硬规则本场涉及：…]
动作行：只写看得见的。主语 + 部位 + 动词 + 对象。情绪名称不能替代具体证据；保留速度、幅度和渐变信息。
角色名
    台词。
    （允许的括号只有：画外 / 对某人 / 停顿 N 秒 / 语言）
动作行：…
```

动作行示例：
- ❌ 她伤心地看着他。
- ✅ 她看着他，手指在杯沿上停住，两秒后把杯子推过去。

## 3c.5 台词

### 通用关（任何参数下每句必过）
| 关 | 检验 |
|---|---|
| 可说出口 | 大声读，不用换气两次 |
| 有意图 | 这句想让对方做什么（Sorkin）；标不出来的删 |
| 不说主题 | 没有解释故事意义的句子 |
| 是这个人说的 | 换成另一个角色说也成立 → 重写 |

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接表达、停顿、打断与结尾由场景、角色声音和可用时间决定；场景参数不是固定配额。既有台词锁定，仅在用户要求修改时改写。

### 执行信息与空泛描述
- 动作行保留可观察的速度、程度、渐变、持续与控制，不因“逐渐”“缓慢”等词而删细节。
- 情绪标签不能代替表演；音量、语速放在“说法”栏，不用空泛态度概括。
- 台词自然度由角色与场景审阅，不计副词配额。下表是可选改写，不覆盖用户锁定原文。
- 替换表：

| 原句 | 副词做的事 | 换成 |
|---|---|---|
| "她冷冷地说：随便。" | 标注态度 | "她说：随便。（停顿 2 秒）她把钥匙推过去。" |
| "他真的真的很想她。" | 加强度 | "他想她。" + 动作行：他把她的杯子洗了，又放回原处。 |
| "他愤怒地摔门。" | 标注情绪 | "他把门摔上，门框上的灰落下来。" |
| "她小心翼翼地问……" | 标注方式 | "她问：……（停顿）……对吧？" |
| "他慢慢地走过去。" | 标注速度 | "他走过去，用了三秒。" |

### 张力六源
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡决定哪几源是主武器：外放用打断与回声，内收用沉默与动作回答，不对等用权力转移，揭秘用重复变义。

### 角色声音表核对
每句台词换成另一个角色说也成立 → 重写。核对声音表的词汇偏好、句长、绝不说的词。

### 每句四件套
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，禁形容词）· 听者（视线 / 手 / 身体）。

## 3c.6 停靠交付（对话内）

每场：参数回显一行 + 剧本页全文 + 节拍表 + 一行"这场改变了什么"。问题：按此进分镜？（或：改哪一句 / 改哪个参数）

用户确认后写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，只出 ✅ / ⚠️ 报告，⚠️ 只用五关判定。

## 3c.7 常见失败

| 现象 | 处理 |
|---|---|
| 转折在台词里 | 改成动作："我不走了" → 把车钥匙放回桌上 |
| 只有情绪形容，没有可见表现 | 补可观察证据；不按“地”或词性判错 |
| 两人对视三十秒 | 回 3c.1 补实际问题与物件 |
| 台词像同一个人写的 | 声音表核对 |
| 需求明确要喊出来，却写成沉默对峙 | 具体表达方向被默认覆盖；按需求修正，不从“吵架”一词机械推断 |
| 每项特征都在，但句与句不推 | 清单式写作；回 §3c.4a 先散文后链，三测 |
| 12 个节拍塞进 30 秒 | 减到 3 个，或拆 clip |
