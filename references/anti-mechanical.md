# 防机械套用规则

本 Skill 的模板和词典是脚手架，不是答案。以下规则在 S3a–S7 全程生效，校验脚本能查的部分已标注代号。

## 1. 选择必须有理由，理由必须指回场景

- 每个透镜、每个运镜、每个外化动作，旁边写一句"因为这场戏……"。写不出来的删掉。
- 理由不能是"更有电影感"、"更高级"。理由必须提到这场戏的具体问题（观众不知道什么、关系怎么变、哪里拍不好）。

## 2. 反向测试

- 每个默认选择做一次反向：固定 ↔ 运动；近景 ↔ 远景；说 ↔ 不说；看见 ↔ 画外；切 ↔ 不切。
- 反向想 30 秒，写一行为什么不是它。反向更好就换。
- 场景卡里保留"反向测试"一行，让下一次修改时能看到当时为什么没选。

## 3. 多样性硬约束

| 约束 | 范围 | 校验 |
|---|---|---|
| 相邻场景不用同一主透镜 | 项目 | 多文件模式 W16 |
| 任一透镜 ≤ 场景数 1/3 | 项目 | 多文件模式 W16 |
| 同一角色同一外化短语 ≤ 2 次 | clip | W14 |
| 同一运镜连续 ≤ 2 镜 | clip | W17 |
| 反套路表中的套路每项目 ≤ 1 次 | 项目 | 人工 |

## 4. 名字不进 Prompt

- 导演、影片、摄影师的名字永远不进 Prompt（W13）。模型对"像 Fincher"没有可观察定义。
- 进 Prompt 的只有可观察量：机位、运镜触发、光源、部位、秒数、声音。

## 5. 去掉测试

- 对每个手法问：如果去掉它，这场戏还成立吗？成立 → 删。
- 对每句台词问：如果换成一个动作，是否更好？是 → 换。
- 对每个外化动作问：换成这个角色绝不会做的动作，是否更有信息？是 → 换（角色声音表里有"绝不会做"列）。

## 6. 词典不是答案

- 外化词典的每一条在用之前改成这个角色的版本：不是"手指摩挲物件边缘"，而是"母亲用拇指摩挲碗沿的缺口"。
- 一个 clip 里同一通道（动作 / 表情 / 视线）不连续使用三次。
- 词典里没有的写法优先于词典里有的。

## 7. 品味门（三问）

S5 结束、S6 开始前，对每个 clip 回答：

1. 这个 clip 里观众会记住的一个画面是什么？
2. 哪一秒是意外？
3. 角色做了什么可见的选择？

三问有任何一个答不出 → 不进 S6，回 S3b 或 S5。

## 8. 模板不是顺序

- 分镜卡的字段是检查清单，不是写作顺序。先想画面，再填表。
- coverage 模式（建立 → 越肩 → 近景 → 反应）是没有更好想法时的兜底，用它要写一行"为什么这场戏不需要视觉方案"。

## 9. 示例不是模板

- 工作示例只放在 `examples/`，任务参考文件里不放答案（模型读到就会照抄）。示例展示的是**流程**，不是答案。示例里的查询、候选、种子、台词、分镜禁止复用到用户项目里。
- 同一题目再次出现时，先做与示例不同的选择（不同处境、不同领域、不同透镜），再判断哪个更好。
- 校验：`scripts/validate_concept.py` 会拦下与示例逐字相同的查询与候选标题。
