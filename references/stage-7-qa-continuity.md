# S7 连续性与质量检查

两个入口：**生成前**（Prompt 校验）与 **生成后**（成片问题定位）。产出 `07_qa/scene-XX-clipYY.qa.md`。

## 7.1 生成前：脚本 + 语义审阅

分别报告：格式、保真、表演质量、成片验证。无错误不等于四项通过。调用及 sidecar 见 `performance-record.md`；没有记录写保真未自动核对，没有成片写未验证。performance/raw 不检查与任务无关的完整生产字段。

1. 运行 `python3 scripts/validate_prompt.py <prompt.md>`；表演片段加 `--artifact performance`，原文加 `--artifact raw --entry-id N`，上游记录用 `--record`。
   - ERROR 必须修。
   - WARN 逐条写"保留理由"或修改。
2. 人工过下表（脚本查不了的）：

| 检查 | 问 |
|---|---|
| 可回溯 | D 层表演能指回 C 层及所选条目？关键细节、顺序、同步与末态有无改变？有意改编记录了吗？ |
| 因果三测 | 每句台词：遮住上一句能猜出它吗 / 删掉它后面还成立吗 / 只做一件事吗（`causal-chain.md`）；每镜：上一镜给了什么、这一镜为什么需要 |
| 因果顺序 | 每个反应前面有起因？`[第三方]` |
| 轴线 | 每镜写了谁在画左谁在画右？换镜后没翻转？ |
| 起止状态 | clip 首尾状态写了？与上下游 clip 对得上？ |
| 外观锁 | 每个角色每个 clip 都有？出画再入画时重复了？ |
| 光源 | 一个主光源，方向一致？ |
| 台词 | 逐字引号、说话人、时间窗、语言、非说话者嘴部？依据显式语速及占比估时，不从情绪强度推算 |
| 多人说话 | 有没有同框同时说话？改越肩/分镜 |
| 表演与时间 | 高光有足够发展与可见持续？控制是否有证据？同步多部位不按逗号算任务；检查无关事件挤占与动作矛盾 |
| 素材 | 编号 = 上传顺序？一素材一职责？超限没有？ |
| 参数 | 有锁定任务 ratio=adaptive？编辑 duration=-1？首尾帧画幅一致？ |
| 风险登记 | 快动作、文字、手部精细动作、多主体 > 5、日/韩长台词 —— 标 ⚠️ 抽卡 |

## 7.2 生成后：成片问题定位

用户给成片 + 问题描述。步骤：

1. **定位秒数** → 找到对应镜头卡（时间戳）。
2. **归类**：

| 现象 | 最可能原因 | 修正层 |
|---|---|---|
| 人物换脸 / 换衣 | 外观锁缺失或素材职责混 | C 层贯穿要求 + 素材绑定 |
| 切镜后人物换边 | 轴线未写 | C 层每镜加画左/画右 |
| 动作被跳过 / 赶 | 该镜内容过多 | 拆镜或减动作，或增秒 |
| 静止不动 | 先确认是否用户目标；也可能细节不可见或未执行 | 查景别、遮挡与表演，不能自动补走位/道具/运镜 |
| 反应先于起因 | 因果顺序 | 拆成两句，先因后果 |
| 情绪不对 | 可能细节丢失、强度/控制错配、时序或可见性不足 | 对照有序表演块与成片逐节拍定位 |
| 台词念错 / 漏 | 引号外描述、时间窗太短、密度高 | 4.5 表 |
| 口型对不上 | 多人同框 / 语言 | 越肩单人；换中文/英文 |
| 出现字幕 / bgm | 没写负向 | 贯穿要求加"不要字幕 / 无 bgm" |
| 多出人或物 | 正向描述不完整 | "画面中只有 A 和 B" |
| 素材元素错位（背景被复制） | 素材未写"不参考什么" | 素材绑定 |
| 快动作形变 | 模型限制 `[第三方]` | 降速 / 减少动作 / 换景别，标风险 |
| 第 25s 后崩 | 长 clip 尾部 | 切两个 clip |
| 编辑后时长/画幅变 | 参数没锁 | ratio=adaptive, duration=-1 |

3. **只改一个变量**再生成。`[第三方]` 记录到 E 层版本号与抽卡记录。
   同时在 `references/validation-log.md` 记一行：测试的写法、对应规则、是否被执行。重复结果仅说明该条件下的经验，不能自动升级成通用能力结论。
4. 若 24/30 秒可用：把可用部分当作素材，只重写坏段的起止状态，用编辑（时间戳范围）或延长处理。`[第三方]`
