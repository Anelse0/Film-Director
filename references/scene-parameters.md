# 场景参数卡

一场戏怎么写台词、怎么演、怎么拍，不由"类型标签"决定，由六个参数决定。参数从需求里提取，在每个停靠点回显给用户确认，下游所有规则都是参数的函数。**没有"克制才是好"的默认美学**：默认值只是参数缺省，不是审美立场。

## 一、六个参数

| 参数 | 取值 | 需求里的线索 | 缺省 |
|---|---|---|---|
| **强度** | 低 / 中 / 高 | 高：吵架、爆发、崩溃、撕、高情绪、激烈；低：安静、日常、克制、淡 | 中 |
| **方向** | 内收 / 外放 | 内收：说不出口、压着、潜台词、暗涌；外放：说出来、喊、摊牌、直接 | 强度高→外放，否则内收 |
| **信息** | 已知 / 揭秘 / 不对称 | 揭秘：真相、发现、原来；不对称：一方不知道、观众知道；已知：双方都清楚在争什么 | 已知 |
| **权力** | 对等 / 不对等 | 不对等：上下级、审讯、求人、病床、一方掌握物件 | 对等 |
| **进场温度** | 冷 / 温 / 灼 | 灼：一开始就在吵 / 已经出事；冷：日常开始 | 强度高→温或灼，否则冷 |
| **密度** | 稀 / 中 / 密 | 密：台词多、快、互相打断；稀：几句话、大量沉默 | 方向外放→密，内收→稀 |

提取规则：需求里出现的线索优先于缺省；线索冲突时（"安静地吵"）两个都保留并在回显里点明；提取不到且会实质改变结果时，在第一个停靠点问一次。

回显格式（每个停靠点第一行）：`参数：强度高 · 外放 · 已知 · 对等 · 进场灼 · 密`

## 一b、表的读法（先读 `causal-chain.md`）

下表里的项是**取值与允许**，不是清单。硬项：句长上限、直接情绪句配额上限、副词、峰值形态、结尾。其余是目标项，一场戏最多选 3 项当设计目标，其余不刻意出现；出现了没有因果的目标项，删。清单全部打勾不等于场景成立。

## 二、参数 → 规则

### 台词（S3c）

| 规则 | 内收 · 低/中 | 外放 · 高 | 说明 |
|---|---|---|---|
| 句长 | 中文 ≤ 15 字 / ≤ 3s | ≤ 25 字，但每 3 句里 ≥ 1 句 ≤ 6 字 | 外放允许长句，靠短句制造节奏 |
| 直接情绪句（"我受够了"） | 禁止 | 每人 ≤ 1 句，只能在"低打击"之后 | 强度高时禁止说情绪反而假 |
| 答非所问 | 一场 ≥ 1 句 | 可用作回避，但升级后必须正面回击 | |
| 打断 / 重叠 | 无 | ≥ 1 次"A 说到一半 B 开口"；≤ 2 次 | 模型执行见 §四 |
| 回声（重复对方的词再反击） | 少用 | ≥ 1 次 | 外放戏的主要武器 |
| 升级阶梯 | 无（一个策略换一次即可） | 三级：小事（物件 / 行为）→ 模式（"你总是"）→ 真正的事（关系 / 身份 / 过去）；每级 ≤ 1/3 时长 | 信息=已知时阶梯必填；揭秘时第三级 = 揭示 |
| 低打击 | 无 | 一句碰到对方"绝不会做 / 旧伤"的话，说完停 ≥ 2s；这是峰值 | 权力不对等时低打击只能由弱势方说，否则是霸凌不是戏 |
| 峰值形态 | 最长的静止 | **突然的低声或沉默**，不是最大声 | 音量曲线：中 → 高 → 高 → 骤低 |
| 结尾 | 一个可见选择 | 不和解；一个人离开或两人都不动，切断 | 30s 内和解是假的 |
| 沉默 | 写成台词（"不回答 + 看着对方 + 2s"） | 只在峰值后出现一次 | |
| 副词 | 动作行零副词；括号无情绪词；台词每句 ≤ 1 非情绪副词 | 同左（音量 / 语速写在"说法"栏，不进括号） | 全参数通用 |

通用关（任何参数下都过）：可说出口 · 有意图（这句想让对方做什么）· 不说主题 · 换成另一个角色说也成立则重写。

### 表演外化（S4）

| 参数 | 通道与幅度 |
|---|---|
| 内收 | 部位级：眼睑、嘴角、手指、吞咽；动作幅度小；一个 clip 内同通道 ≤ 2 次 |
| 外放 | 身体级：走位、转身、拍桌、把东西放下 / 掉落（正向写）、逼近到半米内、挡门；幅度大但每个动作仍写部位与秒数 |
| 强度高 + 峰值 | 峰值动作是**停住**：手停在半空、话说到一半停、转身后不走 |
| 权力不对等 | 弱势方动作朝向物件或地面，强势方动作朝向对方；翻转时对调 |
| 信息不对称 | 知情方多一个"看向证据"的视线；不知情方多一个"看向对方"的视线 |

### 导演与分镜（S5）

| 参数 | 景别 / 运镜 / 切镜 |
|---|---|
| 内收 · 稀 | 固定机位为主；一次缓推；30s ≤ 5 镜 |
| 外放 · 密 | 越肩交替；手持轻晃有视点理由；30s 6–8 镜；峰值切到最长的一镜（≥ 4s） |
| 强度高 | 距离曲线必须变化 ≥ 2 次（远 → 半米 → 一臂） |
| 揭秘 | 一个插入镜头给证据；揭示前后景别跳两级 |
| 不对等 | 高低角度差；弱势方在画面下半或边缘，翻转时换位 |
| 进场灼 | 首镜不建立，直接进中景或越肩；空间靠背景与声音交代 |

### 结构（S3b，30 秒）

| 进场温度 | 0–30s 曲线 |
|---|---|
| 冷 | 0–20 铺（平）→ 20–27 升到灼 → 27–30 切断 |
| 温 | 0–10 升 → 10–22 阶梯 → 22–27 峰值 → 27–30 切断 |
| 灼 | 0–8 已在一级 → 8–18 二级 + 打断 → 18–25 三级 + 低打击 → 25–28 骤低 → 28–30 切断 |

其他格式按比例缩放；多集时每集一张参数卡，相邻两集强度或方向至少变一项。

### 模型执行（S6）

| 参数 | Seedance 2.5 约束 |
|---|---|
| 密 | 每 10s ≤ 4 句；两人交替，时间窗不重叠；设计的打断写成相邻窗（"A 0–3s 说到一半，B 3s 开口"），画内只拍一人脸（越肩），插话者画外 `[推论]` |
| 外放 | 高音量台词写"音量大，语速快，句尾上扬"；物件碰撞音写进声音；不写"愤怒地" |
| 强度高 | 快动作形变风险 `[第三方]`：拍桌、摔门用"接触 → 结果 → 反应"三句，慢一拍 |
| 内收 | 台词 ≤ 1/3 时长；非说话时段嘴部状态必写 |
| 揭秘 | 证据物件在【素材绑定】或【起始状态】里有独立描述 |

## 三、预设 = 参数组合的例子，不是类别

| 预设 | 参数 | 说明 |
|---|---|---|
| 争吵 | 高 · 外放 · 已知 · 对等 · 灼 · 密 | 三级阶梯 + 低打击 + 骤低 |
| 克制告别 | 中 · 内收 · 不对称 · 对等 · 冷 · 稀 | 物件 + 距离 + 一个选择 |
| 审讯 | 中 · 外放 · 揭秘 · 不对等 · 温 · 密 | 权力翻转是转折 |
| 冷面荒诞 | 低 · 外放 · 已知 · 不对等 · 冷 · 中 | 正常语气说不正常的事，零停顿 |
| 喜剧三拍 | 中 · 外放 · 不对称 · 对等 · 温 · 稀 | 笑点不在台词上 |
| 沉默病床 | 高 · 内收 · 已知 · 不对等 · 温 · 稀 | 强度高但内收：动作大、话少 |

需求不匹配任何预设时不要硬套，直接按六参数取值走规则表。

## 四、误用信号

| 信号 | 说明 |
|---|---|
| 需求写了"吵架"但参数回显是内收 | 线索被缺省覆盖，回 §一 |
| 外放戏台词全 ≤ 15 字 | 用了内收句长 |
| 强度高但峰值是最大声 | 峰值应骤低 |
| 低打击由强势方说出 | 变成霸凌 |
| 30s 内和解 | 结尾规则 |
| 参数卡在停靠点没回显 | 用户无法早期纠正 |
