# S5 导演与分镜设计

产出：`03_shots/scene-XX-clipYY.md`，每个 clip 一个文件，内含若干张分镜卡（模板 `templates/shot-card.md`）。本阶段完成 **A–C 层 + E 层**，D 层留给 S6。

## 5.1 先切生产单元（clip）

规则：

1. 一个 clip ≤ 30s，整数秒。`[官方]`
2. **clip 边界落在"空间或时间可自然断开"的地方**：人物出画、门关上、转场、黑场、视线离开。不要在一句台词中间切 clip。
3. **每个 clip 有自己的起始状态与结束状态**（谁在哪、朝向、持物、机位）。结束状态就是下一 clip 的起始状态。
4. clip 衔接策略（三选一，写入 E 层）：

| 策略 | 何时用 | 做法 | 标签 |
|---|---|---|---|
| 延长（续写） | 同一空间、动作连续、需要声画无缝 | 上一 clip 输出 MOV → 作为 `@视频1` 输入，Prompt 写"向后延长 @视频1 N 秒，……"；ratio=adaptive | `[官方]` |
| 尾帧接首帧 | 换镜头 / 换机位但空间一致 | 抽上一 clip 末帧图 → 下一 clip 的 `first_frame`（锁宽高比）或 `reference_image` + "图片 1 为首帧" | `[官方]` + `[第三方]` |
| 独立重生成 | 换场景 / 换时刻 | 只带角色/场景参考素材，各自独立生成，靠外观锁与光源描述保持一致 | `[推论]` |

5. 30s 长 clip 的代价：第 27 秒出错整段重来。`[第三方]` → 剧情复杂、台词多的段落宁可切成两个 15s。

## 5.1b 视觉方案（每场戏一个，先于任何镜头）

在拆镜头之前，用 ≤ 30 字写这场戏**唯一的调度想法**，并写它回答的场景问题与所用透镜（`director-lenses.md`）。例：

- "全片唯一一次镜头主动靠近母亲，其余全部固定。"（L3 静止的理由；问题：怎么让一次推近有分量）
- "女儿出画后镜头再停 5 秒不切。"（L4 画外；问题：分别拍不好）
- "观众先于母亲看见包里的车票。"（L1 信息差；问题：不紧张）

规则：
- 一场一个方案。两个想法 → 拆成两场，或选一个。
- 方案必须能指回项目主控句（S3a）。
- 写反向测试一行（`anti-mechanical.md` §2）。
- 视点归属：写"这场戏是谁的"。所有反应镜头拍这个人；对方的关键动作只从这个人能看到的角度出现（L14）。

## 5.1c 节奏曲线与声音叙事

**节奏曲线**：在 clip 时间轴上标两个点——最长的停顿在哪一秒（≥ 3 秒无动作无台词）、最快的切在哪一秒。两点之间的镜头时长要单调变化（越来越短或越来越长），不要忽长忽短。切点落在情绪变化的瞬间而不是动作完成后（L13）。

**声音叙事**：每场戏指定一个"改变意义的声音"：它第一次出现时是环境，第二次出现时是事件（钟声 → 到点了；关门声 → 走了）。写清两次出现的秒数。这比 bgm 可靠得多，模型对可描述的动作音执行稳定。`[官方]` 案例中动作音一律与可见动作绑定。

## 5.1d 调度模式库（替代 coverage 的第一选择）

coverage（建立 → 越肩 → 近景 → 反应）是兜底。先从下面选一种**空间模式**，它决定人物怎么动、镜头怎么跟：

| 模式 | 人物做什么 | 镜头做什么 | 适合的问题 |
|---|---|---|---|
| 逼近与退让 | 一人向前一步，另一人退半步；反复 2–3 次，最后一次不退 | 固定，让距离变化自己说话 | 权力转移 |
| 交叉 | 两人从画面两侧走向中央，擦身而过，各自到对方原来的位置 | 横移跟其中一人 | 立场交换 |
| 揭示 | 前景遮挡物（门框、肩膀、柜子）移开，露出后景的人或物 | 缓慢横移或人物走开 | 信息差引爆 |
| 镜像 | 两人做同一个动作，一先一后，间隔 2 秒 | 双人固定 | 关系对等或讽刺 |
| 前景遮挡 | 主体被前景部分遮住，只露一部分（手、半张脸） | 固定，焦点在被遮者 | 隐忍、偷看 |
| 背景动作 | 前景静止对话，后景一条动作线从远走近 | 固定或极慢推 | 世界感、威胁临近（L5） |
| 出画停留 | 人物出画后镜头停在空景 ≥ 3 秒 | 固定 | 分别、失去（L4） |
| 单向长镜 | 一个镜头跟一个人从 A 走到 B，途中经过 2 个"站点" | 跟拍 | 纵深调度（L2） |
| 几何阵列 | 三人以上等距站位，一人打破阵列 | 全景固定 | 制度、荒诞（L7） |
| 三拍 | 看见 → 关上 → 再关一层 | 固定，切在动作上 | 视觉喜剧（L9） |

选模式后再决定镜头数。很多模式一个镜头就够，不要为了"有分镜"而切。

## 5.2 镜头设计的顺序

对每个节拍，按这个顺序决定，**不要先想运镜**：

1. **观众此刻需要知道什么**（信息）→ 决定拍谁、拍哪个部位。
2. **关系 / 空间 / 视点是否变化** → 变化才有运镜动机；没变化就固定机位。
3. **景别**：信息量大用全/中景，情绪用近景/特写；一个 clip 内至少有一次景别跳变（≥ 两级）。
4. **轴线与视线**：定两人的轴线，所有镜头在同侧；视线方向逐镜写明（A 看画右，B 看画左）。
5. **起止状态**：这一镜开始时谁在哪、结束时谁在哪。切点选在动作中或动作后，不选在动作前。
6. **时长**：对白镜 3–6s；反应镜 2–3s；动作镜 1.5–3s；建立镜 3–5s。剧情类 30s 内 ≤ 8 镜。`[推论]`

## 5.3 覆盖逻辑（Coverage，兜底）

只有 5.1d 没有合适模式时才用。用它要写一行"为什么这场戏不需要视觉方案"。一个对话场景的最小覆盖：

```
建立（全/中景，两人＋空间＋光源）
→ 关系镜（越肩 或 双人中景，谁主动谁在前景）
→ 说话者近景（台词）
→ 听者反应（近景，必须有可观察变化）
→ 细节插入（手、物件；转折点用）
→ 收束（回到全景 或 单人出画）
```

不是每场都要全部；但**转折点前后必须换景别**，否则观众感受不到"变了"。

## 5.4 运镜有动机

| 动机 | 运镜 | 写法（术语 + 解释） |
|---|---|---|
| 揭示信息 | 摇 / 移 / 后拉 | "镜头向右缓慢横移，露出门口站着的第二个人" |
| 靠近情绪 | 缓慢推 | "镜头以 3 秒缓慢推近到面部近景" |
| 关系失衡 | 环绕 / 高低角度变化 | "镜头从平视缓慢降到低角度仰视" |
| 跟随行动 | 跟 | "手持跟拍，保持人物在画面左三分之一" |
| 空间压迫 | 手持 + 近 | "轻微手持晃动，中近景" |
| 定格判断 | 固定 | "固定机位，全程不动" |

**每镜只写一个主要运镜。** `[官方]` + `[第三方]`。冷门术语（移焦、希区柯克变焦之外的）必须加描述。

## 5.5 连续性锁（每个 clip 写一次，易漂移节拍重复）

- 角色外观锁（S1 提炼的一行）
- 空间：主光源方向、主要陈设、门窗位置
- 轴线：谁在画左谁在画右
- 物件状态：谁拿着、放在哪
- 服装、发型、道具颜色
- 声音环境

## 5.6 分镜卡（五层）

每镜一张，字段见 `templates/shot-card.md`。clip 头部必填：视觉方案 / 透镜 / 视点 / 调度模式 / 节奏曲线两点 / 改变意义的声音。C 层必填项：

```
镜号 / 起止秒 / 景别 / 角度 / 运镜（一个）/ 构图位置
起始状态：谁在哪、朝向、持物
动作（主语 + 部位 + 动词 + 对象）
视线
表情（部位）
台词：说话人 + 引号原文 + 时间窗 + 语言；非说话者嘴部状态
声音：环境 / 动作音 / 有无 bgm
结束状态
光源方向
```

## 5.7 单镜快车道

用户要"一个镜头 N 秒"：只填一张分镜卡，跳过节拍表；但起止状态、视线、光源、声音四项不可省。

## 5.8 从已有分镜 / 镜头表进入

用户给了镜头表：逐镜映射到分镜卡字段，缺什么补什么（最常缺：起止状态、视线、非说话者嘴部、光源、声音）。不改用户的镜头顺序与景别，除非违反 Seedance 约束（单镜 < 1.5s、30s 内 > 10 镜、多人同时说话），此时给出改法并标注。

## 5.9 常见问题

| 问题 | 原因 | 改法 |
|---|---|---|
| 生成结果两人对视不动 | 节拍无策略 / 无物件 / 无距离变化 | 回 S3 |
| 切镜后人物换边 | 未写轴线 | 每镜写"A 在画左，B 在画右" |
| 情绪镜头空 | 只写情绪词 | 查外化词典 |
| 动作被压缩 | 一镜塞了 3 个动作 | 拆镜或减动作 |
| 长 clip 后半崩 | 内容过多 | 切成两个 clip |

## 5.10 群戏、追逐与大空间

透镜和调度模式偏向两三人的室内戏。以下三种段落需要先画"地图"再拆镜头。

### 群戏（≥ 4 人）
1. 先分组：把人分成 2–3 组，每组一个"组长"（有台词或关键动作的人）；其余人只有一条持续动作。
2. 每镜一个焦点人物（L18），画面里其他人按组给位置（"左后景三人围桌"）。
3. 有素材参考的主体 ≤ 5，其余靠外观锁一行。`[官方]`
4. 台词只给组长；一镜一人说话。
5. 群体反应写成一个可观察量："桌边三人同时停下筷子"，不写"大家很惊讶"。

### 追逐
1. 地图三点：起点、一个障碍、终点（或转折点），各给一个可见地标。
2. 屏幕方向锁定：追者与被追者全程同一方向（画左 → 画右），只在障碍处允许一次反向，且用一个镜头明确交代反向。
3. 每镜写两人的相对位置："被追者在画右三分之一，追者在画左边缘刚入画"，距离用身位数。
4. 每镜一次事件：跨过、撞到、丢下、抓住一次。
5. 镜头与主体运动方向一致（横移或跟拍），不环绕。
6. 30s ≤ 8 镜；单镜 ≥ 2s；快动作形变风险标注。`[第三方]`

### 大空间（跨越多个房间 / 街区）
1. 一个 clip 只在一个空间；跨空间就切 clip，衔接用尾帧接首帧。
2. 每个空间开场一镜交代出入口与主光源。
3. 人物穿过门/转角时重复外观锁一行。`[第三方]` 遮挡后重复身份。
4. 声音环境随空间变化，写清变化的秒数（"第 6s 穿过门后街道噪音进入"）。
