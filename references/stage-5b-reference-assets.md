# S5b 参考资产准备

本阶段适用于完整 production。performance/raw 是文本表演交付，不因缺少图而等待，不把情绪库条目当成视频参考；实际有素材时才登记引用。

**图 + 文是核心生产路径，文生视频是兜底。** `[官方]` Seedance 2.5 的主体参考、场景参考、关键帧参考是它区别于前代的能力；`[第三方]` 多家实践一致：没有参考图时跨 clip 角色一致性风险较高。所以在完整生产的 S6 编译之前，先有资产计划。本 Skill 不生成图片，但产出**资产清单 + 每张图的图像简报**（模型无关），用户用任何图像模型生成后回填。

输入：`03_script/` 剧本 + `04_shots/` 分镜卡。输出：`05_assets/asset-plan.md`（模板 `templates/reference-asset-brief.md`）+ 更新 IP 级 `assets/assets.md` 登记表。

## 5b.1 从分镜推资产清单

| 资产类型 | 什么时候需要 | 规格 | 数量建议 `[官方]` |
|---|---|---|---|
| 角色主体图 | 每个有脸的角色 | 正面中近景、中性表情、干净背景、服装与外观锁一致；侧面一张（2.5 支持多视图，**拆成多张单视图上传**，不拼图） | 每角色 1–3 张；总主体 1–8 稳定 |
| 场景空镜 | 每个机位方向一张 | 无人物；含主光源与方向、主要陈设、门窗位置；与分镜卡的景别一致 | 每场景 1–3 张 |
| 道具 | 有特写或归属变化的物件 | 干净背景、真实尺寸感 | 每件 1 张 |
| 关键帧 | 走 T4 关键帧路径时 | 按镜头顺序，每镜首帧；构图 = 分镜卡 | 每镜 1 张，≤ 15 |
| 音色 | 有台词角色需要固定音色时 | 5–10s 干净人声，语言与台词一致 | 每角色 1 段 |
| 动作 / 运镜参考 | 复杂动作或精确运镜 | 5–10s，只含要参考的那一件事 | 按需 |

上限核对：图 ≤ 30、视频 ≤ 10 总 ≤ 30s、音频 ≤ 10 总 ≤ 30s、合计 ≤ 50。`[官方]`

## 5b.2 图像简报（每张一份，模型无关）

```
资产 ID：img_（上传顺序编号在 5b.4 定）
用途：角色 A 主体参考 / 场景 X 机位 1 空镜 / …
主体：外观锁原文（角色）或空间描述（场景）
构图：景别、角度、主体位置、背景是否干净
光：主光源 + 方向 + 质地（必须与该场景所有镜头一致）
风格：媒介 / 质感 / 色调（与 ip.md 视觉总则一致）
一致性标记：这张图里必须出现、后续每个 clip 都靠它认人的 2–3 个特征（疤、配饰、发型、服装颜色）
不要：文字、水印、多人、道具堆、极端表情、复杂背景（角色图）
```

一致性标记同时写进外观锁；每个 clip Prompt 的【贯穿要求】重写这 2–3 个特征。

## 5b.3 编排原则

- **一图一职责**：角色图不当场景图用；需要"角色在场景里"的效果靠 Prompt 组合，不靠一张合成图。`[官方]` 一素材一职责。
- **同一角色多张图必须同一服装、同一发型**，除非剧本有换装，换装另起一组。
- **场景图的光要和剧本时刻一致**：夜戏不能用白天空镜。
- **不在图上写字**，不靠图上文字指代角色。`[官方]`

## 5b.4 上传顺序与编号

在 `asset-plan.md` 里定最终上传顺序：角色 → 场景 → 道具 → 关键帧 → 音频 → 视频。编号即 Prompt 里的 图1 / 音频1 / 视频1。顺序一旦改动，所有 Prompt 同步改。

## 5b.5 回填与降级

- 用户生成图后：把文件名回填到 `assets/assets.md` 登记表，S6 才编译。
- 缺角色图：该角色只能靠外观锁文字，跨 clip 一致性标 ⚠️ 高风险；可先用 T1 文生视频出一条，从中抽帧当参考图（自举）。`[推论]`
- 缺场景图：可用第一条成片的末帧或抽帧当场景参考。`[第三方]` 末帧续接。
- 用户明确接受不一致风险且要求快出：走 T1 兜底，Prompt 文件 E 层标"兜底路径"。

## 5b.6 停靠

S5b 不单独停靠。资产清单随 S5 分镜一起交付，用户确认分镜时一并确认资产清单；用户生成图并回填是一个自然的等待点。
