# S5 导演与分镜设计

输入：已确认剧本页的 S4 有序表演块，或直接表演需求。完整流程按运行模式停靠并附资产清单；直接测试只检查关键部位可见，不触发故事或资产停靠。

产出：`04_shots/scene-XX-clipYY.md`，每个 clip 一个文件，内含若干张分镜卡（模板 `templates/shot-card.md`）。本阶段完成 **A–C 层 + E 层**，D 层留给 S6。

## 5.1 先切生产单元（clip）

规则：

1. 一个 clip ≤ 30s，整数秒。`[官方]`
2. **clip 边界落在"空间或时间可自然断开"的地方**：人物出画、门关上、转场、黑场、视线离开。不要在一句台词中间切 clip。
3. **每个 clip 有自己的起始状态与结束状态**（谁在哪、朝向、持物、机位）。连续衔接时核对末态与下一初态；有意跳时空则明确新状态及省略，不强行接成同一瞬间。
4. clip 衔接策略（三选一，写入 E 层）：

| 策略 | 何时用 | 做法 | 标签 |
|---|---|---|---|
| 延长（续写） | 同一空间、动作连续、需要声画无缝 | 上一 clip 输出 MOV → 作为 `@视频1` 输入，Prompt 写"向后延长 @视频1 N 秒，……"；ratio=adaptive | `[官方]` |
| 尾帧接首帧 | 换镜头 / 换机位但空间一致 | 抽上一 clip 末帧图 → 下一 clip 的 `first_frame`（锁宽高比）或 `reference_image` + "图片 1 为首帧" | `[官方]` + `[第三方]` |
| 独立重生成 | 换场景 / 换时刻 | 只带角色/场景参考素材，各自独立生成，靠外观锁与光源描述保持一致 | `[推论]` |

5. 长 clip 后段失败会增加返工成本；先检查负载及局部编辑可行性，再考虑拆 clip，不固定拆成两个 15s。

## 5.1b 视觉方案（每场戏一个，先于任何镜头）

在拆镜头之前，简明写这场戏**主要调度意图**，并写它回答的场景问题与所用透镜（`director-lenses.md`）。例：

- "全片唯一一次镜头主动靠近母亲，其余全部固定。"（L3 静止的理由；问题：怎么让一次推近有分量）
- "女儿出画后镜头再停 5 秒不切。"（L4 画外；问题：分别拍不好）
- "观众先于母亲看见包里的车票。"（L1 信息差；问题：不紧张）

规则：
- 用连贯的视觉意图协调多个手法；不因有两个想法就强制拆场。
- 方案必须能指回项目主控句（S3a），并说明概念卡"独特之处"在本场的哪个镜头里看得见。
- 写反向测试一行（`anti-mechanical.md` §2）。
- 视点归属：说明观众此刻跟谁、知道什么；可持续或有意转移，不强制全部反应镜头只拍一人。

## 5.1c 节奏曲线与声音叙事

**节奏曲线**：先保证表演高光有时间完成且可见，再按信息与情绪选择切点。无需必有静止、最快切、单调镜长或固定停顿；表演时间段不等于镜头切换。

**声音叙事**：按需选择有意义的环境/动作声音；纯表演可只留呼吸，不强制声音母题或两次出现。

## 5.1d 调度模式候选

coverage 与长镜调度都是候选，按信息与表演可见性选择；下表是示意，不是动作次数/停顿配额：

| 模式 | 人物做什么 | 镜头做什么 | 适合的问题 |
|---|---|---|---|
| 逼近与退让 | 一人向前一步，另一人退半步；反复 2–3 次，最后一次不退 | 固定，让距离变化自己说话 | 权力转移 |
| 交叉 | 两人从画面两侧走向中央，擦身而过，各自到对方原来的位置 | 横移跟其中一人 | 立场交换 |
| 揭示 | 前景遮挡物（门框、肩膀、柜子）移开，露出后景的人或物 | 缓慢横移或人物走开 | 信息差引爆 |
| 镜像 | 两人做同一个动作，一先一后，间隔 2 秒 | 双人固定 | 关系对等或讽刺 |
| 前景遮挡 | 主体被前景部分遮住，只露一部分（手、半张脸） | 固定，焦点在被遮者 | 隐忍、偷看 |
| 背景动作 | 前景静止对话，后景一条动作线从远走近 | 固定或极慢推 | 世界感、威胁临近（L5） |
| 出画停留 | 人物出画后按余韵需要停在空景 | 固定 | 分别、失去（L4） |
| 单向长镜 | 一个镜头跟一个人从 A 走到 B，途中经过 2 个"站点" | 跟拍 | 纵深调度（L2） |
| 几何阵列 | 三人以上等距站位，一人打破阵列 | 全景固定 | 制度、荒诞（L7） |
| 三拍 | 看见 → 关上 → 再关一层 | 固定，切在动作上 | 视觉喜剧（L9） |

选模式后再决定镜头数。很多模式一个镜头就够，不要为了"有分镜"而切。

## 5.2 镜头设计的顺序

对每个节拍，按这个顺序决定，**不要先想运镜**：

1. **观众此刻需要知道什么**（信息）→ 决定拍谁、拍哪个部位。
2. **运镜的作用** → 可来自跟随、揭示、主观感受、韵律或视觉变化；静止与运动都须服务本场。
3. **景别**：信息量大用全/中景，情绪用近景/特写；景别是否变化以可见性和信息为准，不设跳变要求。
4. **轴线与视线**：区分物理位置与屏幕位置；逐镜写明，有意越轴用运动或中性角度交代，不能写与走位冲突的“永远画右”。
5. **起止状态**：核对位置、持物与动作阶段，切点可在动作前/中/后，按信息与节奏决定。
6. **时长**：先安排台词窗口和关键动作，再检查同镜同步与前后依赖；不按景别分配固定秒数。

## 5.3 覆盖逻辑（Coverage，可选方案）

按需要选择这些角度，不用证明其他模式失败才允许使用：

```
建立（全/中景，两人＋空间＋光源）
→ 关系镜（越肩 或 双人中景，谁主动谁在前景）
→ 说话者近景（台词）
→ 听者反应（按意图呈现变化或有控制的持续状态）
→ 细节插入（手、物件；转折点用）
→ 收束（回到全景 或 单人出画）
```

不是每场都要全部；转折也可以在同一近景中由表演呈现，不强制换景别。

## 5.4 运镜有动机

| 动机 | 运镜 | 写法（术语 + 解释） |
|---|---|---|
| 揭示信息 | 摇 / 移 / 后拉 | "镜头向右缓慢横移，露出门口站着的第二个人" |
| 靠近情绪 | 缓慢推 | "镜头以 3 秒缓慢推近到面部近景" |
| 关系失衡 | 环绕 / 高低角度变化 | "镜头从平视缓慢降到低角度仰视" |
| 跟随行动 | 跟 | "手持跟拍，保持人物在画面左三分之一" |
| 空间压迫 | 手持 + 近 | "轻微手持晃动，中近景" |
| 定格判断 | 固定 | "固定机位，全程不动" |

**每镜明确主要运动，复合运镜写清同步或先后，避免矛盾。** `[本地写作建议]` 热门运镜可直接写，小众术语加描述 `[官方建议]`。摄影工具与动机依据见 `director-lenses.md`。

## 5.5 连续性锁（每个 clip 写一次，易漂移节拍重复）

- 角色外观锁（S1 提炼的一行）
- 空间：主光源方向、主要陈设、门窗位置
- 轴线：谁在画左谁在画右
- 物件状态：谁拿着、放在哪
- 服装、发型、道具颜色
- 声音环境

### 关键事件的物理可见性

先验证 C 层自身成立，再核对 D 是否忠实。只对影响事件的空间关系追踪：物件从哪到哪、谁的手在操作、可否同时完成、观众通过哪一机位看见。戏中手机镜头与拍摄本片的摄影机是两个视点；手机在桌上方朝前，不会自动拍到桌下的人。若需要照片结果，必须说明手机镜头朝向、主体位置及遮挡，不能靠结果句跳过动作。

改可见性牵动锁定走位或表演时回上游协商；不要为每句对白塞递物和走位。镜头、表演节拍、台词窗口共用 clip 时间轴，同步时间不相加，串行动作不伪装为同步。

## 5.6 分镜卡（五层）

每镜一张，字段见 `templates/shot-card.md`。clip 头部按需要记录视觉方案、视点与节奏；透镜、调度模式和声音母题不是填满清单。表演块正文从 S4 原样承接；其他字段只补缺项，不能拆散已有先后与同步关系。C 层检查项：

```
镜号 / 起止秒 / 景别 / 角度 / 运镜（复合时说明关系）/ 构图位置
起始状态：谁在哪、朝向、持物
动作（主语 + 部位 + 动词 + 对象）
视线
表情（部位）
台词：说话人 + 引号原文 + 时间窗 + 语言；非说话者嘴部状态
声音：环境 / 动作音 / 有无 bgm
结束状态
光源方向
```

## 5.7 单镜快车道

用户要“一个镜头 N 秒”：只用一张镜头卡，但保留必要的镜内表演节拍。直接测试按 `emotion-performance.md` 交付，不强制完整卡；起止状态和高光可见性仍需核对。

## 5.8 从已有分镜 / 镜头表进入

用户给了镜头表：逐镜映射到分镜卡字段，缺什么补什么（最常缺：起止状态、视线、非说话者嘴部、光源、声音）。保持用户镜头顺序与景别。快切、镜头过密或多人同框对白属于执行风险，不自动当作硬限制；说明风险与可选调整，不擅自覆盖锁定设计。

## 5.9 常见问题

| 问题 | 原因 | 改法 |
|---|---|---|
| 生成结果两人对视不动 | 可能是有意持续，也可能遗漏已写反应、可见性不足或生成执行失败 | 先对照已确认 C 层与成片；只有交流本身不成立才回 S3，不自动添加物件或走位 |
| 切镜后人物无故换边 | 物理位置/机位关系不清 | 逐镜核对轴线与走位；有意过轴不直接判错 |
| 情绪镜头空 | 只写情绪词 | 查外化词典 |
| 动作被压缩 | 无关任务挤占时间或高光窗口不足 | 减少无关事件或增时；同一行为的多部位联动不按动作数量删减 |
| 长 clip 后半崩 | 需定位身份漂移、遮挡、动作负载或其他实际失败 | 先查局部修正；拆分需保护台词、高光与状态，不能默认两段 15s |

## 5.10 群戏、追逐与大空间

透镜和调度模式偏向两三人的室内戏。以下三种段落需要先画"地图"再拆镜头。

### 群戏（≥ 4 人）
1. 按剧情关系分组，说明主要交流对象与背景活动；人数/分组数不固定。
2. 按叙事选择焦点（可单人或群体），画面里其他人按需要给位置（"左后景三人围桌"）。
3. 按实际主体逐一绑定参考；主体图 1–8、主体音视频 1–5 是指南较稳定区间，不是超过就删参考的上限。真正媒体上限见能力表。
4. 台词按人物需要分配，重叠对白与多人口型属于执行风险，给时间窗/画内外安排，不自动删除。
5. 群体反应写成一个可观察量："桌边三人同时停下筷子"，不写"大家很惊讶"。

### 追逐
1. 地图三点：起点、一个障碍、终点（或转折点），各给一个可见地标。
2. 明确运动方向，反向时交代空间与触发事件，不限定只能反向一次。
3. 每镜写两人的相对位置："被追者在画右三分之一，追者在画左边缘刚入画"，距离用身位数。
4. 常规动作概括，关键接触点细写；一次或多次事件取决于镜长和参考材料。
5. 按可读性选跟拍、横移、环绕或固定，不把一种运动当作唯一方案。
6. 标注快动作/快切的实际风险，不设置统一镜数和秒数配额。

### 大空间（跨越多个房间 / 街区）
1. 同一 clip 可以跨空间；明确路径、切点和新空间，超出时长承载才拆 clip。
2. 每个空间开场一镜交代出入口与主光源。
3. 人物穿过门/转角时重复外观锁一行。`[第三方]` 遮挡后重复身份。
4. 声音环境随空间变化，写清变化的秒数（"第 6s 穿过门后街道噪音进入"）。
