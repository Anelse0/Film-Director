## P0 验收：同一请求换种说法不改变范围、保存与审美

`scripts/route_check.py` 对下列改写给出相同的意图 / 入口 / 自主度 / 保存（`tests/test_routing.py`）：

| 改写对 | 结果 |
|---|---|
| "帮我想几个关于搬家的方向" / "搬家这个题，构思几个版本" | 想故事 → S3a，不落盘 |
| "写一个关于搬家的短片" / "给我写一部讲搬家的短片" | 写完整剧本 → 概念 ▮ 故事 ▮ 剧本 ▮，停靠确认后落盘 |
| "这段台词太假" / "这句对白太直白了，改改" | 局部改写 → 诊断层级 → 定点重写 |
| "这是剧本，帮我拆分镜" / "剧本在这，分镜拆一下"（材料=成熟剧本） | 进入生产 → S4 → S5 |
| 同一请求 + "看看效果" | 只改自主度与保存，审美字段不变 |
| 同一请求 + "存一下候选" | 只改保存 |
| 两句对白的片段 + "拆分镜" | 不进 S4：材料未成熟，先补故事 / 剧本 |

脚本是确定性自检，不替代阅读需求；对"嗯"这类无法判断的输入输出"需确认"。
