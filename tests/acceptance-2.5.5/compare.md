# 三配置非盲对照（2.5.5 第三层验收，未开始）

目的：区分改善来自解除限制（P0），还是新增故事开发方法（P1–P3）确实有贡献。全程不用子代理；同一上下文生成和评审，偏差明确承认。

## 三种配置

| 配置 | Git 引用 | 含义 |
|---|---|---|
| 原版 2.5.0 | `v2.5.0` | 基线 |
| 只做 P0 清理 | `v2.5.5-p0` | 统一路由、去门槛、校验修复，无新方法 |
| 完整 2.5.5 | `v2.5.5` | P0 + 故事开发方法 + 对白修订 + 修订账本 |

```bash
cd <skill 目录>
git worktree add ../film-director-2.5.0 v2.5.0
git worktree add ../film-director-2.5.5-p0 v2.5.5-p0
```

## 方法

- 同题、同模型、相近预算；每个配置在独立会话里加载对应版本的 Skill，输入同一条需求。
- 保留全部结果（不挑样本），每题记录：三份输出 / 具体差异（指出句子、候选、人物）/ 失败、持平、退步各自在哪。
- 只读故事正文做第一轮判断，再看分析说明。
- 不计算胜率，不用 `blind_eval.py` 包装成盲测；用户愿意盲选时另按 `tests/creative-eval.md` 执行。
