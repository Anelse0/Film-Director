# 六类回归护栏：非盲文本与确定性检查分开

## G1 无对白与合作，不强加冲突

输入：10 秒固定中景，两位朋友一起把靠垫放好，安静合作，禁止加新矛盾。

输出：0–4s，两人坐在沙发上，A把歪斜的靠垫扶正；B扶住另一侧，使靠垫保持竖直。4–10s，A松手，向后靠住，B也松手靠回自己的位置。两人视线从靠垫转向前方，嘴唇自然闭合；没有台词，只留衣料摩擦与室内环境音。

自审：一次共同动作与松手顺序可理解，无新增冲突、策略转换或价值观争论。10秒是否拖沓仍待观看，不把安静自动判好。此为片段，不冒充有真实素材的生产包。

这证明程序与资产约束未损伤，不证明任意新编大哭一定好看。没有改动原库，也没给原始25条加入来源地址。

## G4 定点改稿，不借机换故事

输入锁：桌上有一盏灯，一块布在灯右侧。A要把灯装箱，B想留着继续用。仅修动作连续性；以下台词和结尾不改。

初稿：

```text
布放在灯右侧。A把纸箱放在桌边。
A：灯也装进去？
B：这个先别装。
A从灯底下抽出布，放进箱子。
A：那我把箱子留这儿。
```

修订：只将动作改为“A拿起灯右侧的布，放进箱子。”其余逐字保留。

自审：删除凭空出现在灯下的状态，没有为了接通状态新编抬灯、垫布两步。收益是连续性清楚、动作负载不增加；损失是原稿抽布时可能牵动灯的戏，但该戏没有输入依据。没有把“这个先别装”换成“留下我们的光”之类主题句。

## G5 锁定内容与事实边界

输入：只体检上段，不改稿；另有人建议用“医院一律不让未婚伴侣见面”制造阻力，但没有指定地区、机构、日期或授权扩大研究。

输出：体检只指出布的位置冲突，不写替换稿；制度建议没有可用依据，不采用为真实阻力，也不补法律结论。可在用户要求发展该方向时核实具体规则，或经选择明确改为架空制度。

自审：未发生外部写入或代用户改锁定内容；这项检验的是不凭空补事实，不是医院规则调研。研究资源中的医疗身份断言已移除，以明确虚构的非医疗例子替代。

## G6 道具视点与生产闭环

新题：孩子趴在透明度为零的实木桌下，成年人手机在桌上朝前，要求自拍里同时看到孩子。不能改桌子透明或让孩子瞬移。

诊断：原条件下镜头被桌面遮挡，不因写出“照片里有孩子”便成立。可选改动是成人蹲低，将手机放到桌沿下方朝向桌下；这改变了已锁定机位，先提出供用户选择，不擅自执行。拍摄本片的摄影机看见两人，不等于戏中手机能拍见两人。

独立正式生产 Demo：`demo.upstream.md` → `demo.prompt.md` → `demo.production.json`。本例没有照片视点难题，专测30秒台词/表演/连续性与编译闭环；不能用该 Demo 自动通过前述遮挡题。严格预检读取真实文件和哈希，无参考素材，T2V测试用途明确；成片未验证。既有真实 PNG 颜色夹具另验证 R2V 媒体检查，不冒充角色外观验证。
