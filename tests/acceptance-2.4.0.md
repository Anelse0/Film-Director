## 三、实施内容

分三批提交，见 `CHANGELOG.md` [2.4.0]：P0 解除干扰（概念协议 / S3a / 校验器 / 夹具 / 入口 / 残留矛盾）· P1 创作与重写能力（两侧问题、叙事方式、人物声音、对白审阅、回路与重写、偏好账本、方法资源四段式）· P2 评测（盲选协议、覆盖矩阵、打包 / 记录 / 揭晓工具）。

对方案的两处解释性调整：
1. "取消题材禁令"实施为：旧"禁用表"改为"默认地图"，落在地图上的候选须写出人物 / 事件 / 观众理解上的差异；删除"默认处境最多占一条查询"及对应 C04 错误。集中研究一个题材合法，只换地点不合法。
2. 候选数量不固定，但校验器仍要求 ≥ 1 个完整候选块与创作判断；这是交付完整性，不是创意约束。
