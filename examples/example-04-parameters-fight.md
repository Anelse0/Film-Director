# 示例 04：30 秒〈行李箱〉，保留有效戏剧设计

本例是“高情绪男女争执”的一种选择，不把高强度自动映射为外放、密台词或固定镜数。完整 Prompt 见 `example-04-parameters-fight.prompt.md`；它是带素材槽位的案例文本，尚无该人物/场景的实际图片，不能冒称可提交 R2V 生产包。

## 保留的创作依据

她用收袜子留人，他用“六点的飞机”结束话题；她把一次安排指认为反复缺席，他刚要承诺便被熟悉的旧话堵住；于是他把责任推回她的加班。三秒沉默后，她只说“我今天回来了”。他没接住，她离开，门没有关。

这条回应链、七条逐字台词、袜子弹出、回声、截断承诺、踢箱盖、三秒沉默、低声短句和未关门结尾均保留。沉默在本场有效，不推广成所有高强度情绪必须骤低。三次“六点的飞机”分别由两人说出，不因重复删掉。

## 时序与连续性修复

| 窗口 | 内容 | 编排依据 |
|---|---|---|
| 0–3s | 扔袜子与责问 | 动作、台词同步 |
| 3–6s | 不抬头继续叠衣，报时间 | 保留回避回应 |
| 6–11s | 向前半步，重复控诉 | 22 字左右快语速，单独提示估时风险 |
| 11–15s | 未完承诺，画外截断 | 两条独立窗口，只拍周远的脸 |
| 15–21s | 起身踢合箱盖、逼近半步、反击 | 台词与动作同步，不靠压缩串行动作 |
| 21–27s | 三秒沉默，然后低声短句 | 保留原高光，不额外强加哭泣 |
| 27–30s | 她经他后方进入近旁卧室 | 三秒交代转身/短距离移动，门不关 |

原来的箱盖合拢后结尾又敞开、许彤向左走却“始终画右”均改为一致状态。仍保留七镜和总时长30秒；没有机械拆成两条15秒。白衬衫的左右手承接已说明。

## 验收边界

运行 `python3 scripts/validate_prompt.py examples/example-04-parameters-fight.prompt.md --json` 可复查时间、台词和参数。镜头3快速长句的估时警告应保留并排练核对；不能删原句或调快全场语速来消警告。镜头5快动作、画外截断和三秒沉默需要真实生成检验。
