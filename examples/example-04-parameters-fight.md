# 示例 04：同一需求，参数卡决定写法

需求："男女吵架，30 秒，高情绪。看一眼模式：先出一个 prompt 看台词。"

本示例只证明一件事：**参数卡不同，同一套规则产出完全不同的戏。** 示例 01〈钥匙〉是 `中 · 内收 · 不对称 · 对等 · 冷 · 稀`，本例是 `高 · 外放 · 已知 · 对等 · 灼 · 密`。两者用的是同一份 `stage-3c-script.md`，只是参数关取值不同。台词、人物、物件禁止复用。

## 参数回显

参数：强度高 · 外放 · 已知 · 对等 · 进场灼 · 密（需求线索："吵架"→高/外放/已知；"高情绪"→灼；30s + 吵架 → 密）

## 参数 → 规则取值（来自 scene-parameters.md §二）

- 句长 ≤ 25 字，每 3 句里 ≥ 1 句 ≤ 6 字
- 直接情绪句每人 ≤ 1，且在低打击之后
- 打断 ≥ 1 次（相邻时间窗，画内只拍一人脸）
- 回声 ≥ 1 次
- 三级阶梯：小事（袜子 / 行李箱）→ 模式（"你每次"）→ 真正的事（谁先不回家）
- 低打击一句，说完停 ≥ 2s；峰值骤低
- 结尾不和解，切断
- 30s 曲线（灼）：0–8 一级 / 8–18 二级 + 打断 / 18–25 三级 + 低打击 / 25–28 骤低 / 28–30 切断
- 分镜：越肩交替，6–8 镜，距离曲线变化 ≥ 2 次，峰值切到最长一镜

## 因果链（剧本页之前）

散文：她把袜子扔进箱子是在帮他收拾，袜子弹出来是因为她扔得用力，因为她不想他走。他答"六点的飞机"是在用时间表结束话题。她把"六点"重复三次，因为这个时间表就是她要控诉的东西。他说"下周就"是想承诺，被打断是因为承诺她听过。他反击"你自己哪天九点前进过门"，因为被逼到墙角只能把她的过错拿出来，而这正是她的旧伤。她三秒不动，因为这句是真的。她低声说"我今天回来了"，因为这是唯一能反驳的事实，也是她今天才做出的改变。他手停住，因为他明白了她改了而他要走。她进卧室门没关，因为她没有把话说完。

```
[1] 起点 → 她要他别走 → 扔袜子（用力，弹出）→ 他听到的是"你连这个都做不好"
[2] 被指责 → 他要结束话题 → "我明天六点的飞机" → 她听到的是"时间表比你重要"
[3] 被时间表挡开 → 她要把时间表变成罪证 → 回声"六点"三次 → 他被"每次"钉住
[4] 被钉住 → 他要承诺 → "我下周就——" → 她听到又一个承诺
[5] 又一个承诺 → 她要堵住承诺 → 打断"你上周也这么说" → 他没有退路
[6] 没有退路 → 他要把责任推回去 → 踢箱盖 + "你自己哪天九点前进过门"（低打击：她的旧伤是加班）→ 她被说中
[7] 被说中 → 她要用事实反驳 → 三秒不动 + 低声"我今天回来了" → 他明白她改了
[8] 明白了 → 他要说什么但没有 → 手停住 → 她没等到回答
[9] 没等到 → 她要结束 → 进门，门没关 → 切断
```

目标项（≤ 3）：回声、打断、低打击。三测：每句遮住上一句都能猜出（回答 / 反击 / 堵）；删掉任一句后一句失去成立条件；每句一件事。"行李箱 / 飞机 / 门"在被说出前都已在画面里。

## 剧本页（节选）

```
场 01 〈行李箱〉 · 家 · 深夜
参数：高 · 外放 · 已知 · 对等 · 灼 · 密

周远蹲在敞开的行李箱前叠衬衫。许彤把一双卷好的袜子扔进箱子，袜子弹到地上。

许彤
    你连袜子都不会放了？

周远
    我明天六点的飞机。

许彤
    你上个月也是六点的飞机。你每次都是六点的飞机。

周远
    我下周就——

许彤
    你上周也这么说。

周远站起来，一脚把行李箱盖踢上。箱盖弹开又落下。

周远
    你嫌我不回家？你自己哪天九点前进过这个门？

许彤不动。三秒。

许彤
    （音量低）我今天回来了。

周远的手停在衬衫上。许彤转身走进卧室，门没关。
```

阶梯：袜子（小事）→ "每次都是六点"（模式）→ "你自己哪天九点前进过门"（真正的事，低打击，碰到她的"绝不会做"：她答应过不再加班）。打断：周远"我下周就——"被切。回声："六点的飞机"重复三次变义。峰值骤低："我今天回来了"是全场唯一的直接情绪句，在低打击之后，音量低。结尾不和解，门没关是切断点。

## 与示例 01 的对照

| | 示例 01〈钥匙〉 | 示例 04〈行李箱〉 |
|---|---|---|
| 参数 | 中 · 内收 · 不对称 · 对等 · 冷 · 稀 | 高 · 外放 · 已知 · 对等 · 灼 · 密 |
| 台词 | 3 句，全 ≤ 6 字 | 8 句，最长 22 字，含打断 |
| 直接情绪句 | 0 | 1（峰值） |
| 峰值 | 手停在碗沿 2 秒 | 骤低的一句 |
| 距离曲线 | 两步 → 半米 → 一臂 | 蹲 / 站 → 踢箱 → 三秒对峙 → 出画 |
| 镜数 | 4 | 7 |
| 结尾 | 女儿出画，母亲看碗 | 卧室门没关 |

规则同一套。差别全在参数。
