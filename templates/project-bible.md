# 项目 Bible 模板

复制到 `<project>/01_bible/`，拆成 world.md / characters.md / locations.md / assets.md（assets 用 asset-registry.md）。

## world.md

```
# 世界观
时代 / 地区：
技术或魔法边界（能做什么、不能做什么）：
社会规则（3 条以内，会影响人物行为的）：
视觉总则（媒介、色调、光的性格、镜头质感 —— 全部可见量）：
声音总则（这个世界常有的声音；有无音乐；音乐性格）：
禁忌（绝不出现的东西，正向写成"总是出现什么"以便进 Prompt）：
```

## characters.md（每人一段）

```
# 角色：〈名〉
外观锁（≤40 字，可观察，每个 clip 重写）：
  例："三十岁上下女性，齐肩黑发，左眉一道短疤，深灰羊毛大衣，黑色手套"
素材：img_ / aud_（音色）
说话方式：语速 / 音量 / 口头禅 / 方言 / 语言
身体习惯（2 个可观察小动作）：
欲望（这个故事里）：
恐惧：
与他人关系（对每个主要角色一行）：
禁止（TA 绝不会做的可观察行为）：
```

## locations.md（每处一段）

```
# 地点：〈名〉
布局（入口 / 窗 / 主要陈设 / 人物常在位置）：
主光源与方向（按时刻分别写）：
声音环境：
可用物件（3 个以内）：
素材：img_
```
